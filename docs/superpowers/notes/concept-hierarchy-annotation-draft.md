## Notes & Concerns

### 닭-달걀 관계 (parent 방향이 양방향으로 읽힐 수 있는 쌍)

1. **함수적 종속성 ↔ 정규화**: 정규화.md "[[함수적 종속성]] — 정규화의 기반"이라 하므로 함수적 종속성이 정규화의 prereq처럼 보임. 그러나 함수적 종속성은 정규화 단원 내에서만 등장(소스가 동일 강의 주차). parent를 정규화로 잡되 확인 필요.

2. **데이터마이닝 ↔ 데이터 전처리·유사도**: 데이터마이닝이 이 둘을 `## 관련`에 선행으로 명시하지만, 실제로는 데이터마이닝이 umbrella이고 나머지가 하위 지원 개념. reviewer가 방향을 뒤집을 경우 데이터 전처리·유사도의 parent를 데이터마이닝으로 이동.

3. **Memex ↔ LLM Wiki Pattern**: LLM Wiki Pattern이 Memex의 현대 계승자("direct descendant in spirit")이므로 Memex가 역사적으로 선행. 그러나 Memex 페이지가 LLM Wiki Pattern에 `## Relation to` 절로 종속되어 있음 — 방향이 애매. 두 페이지 모두 root로 두거나, Memex를 역사 페이지 루트로 LLM Wiki Pattern의 prereq으로 처리하는 방안도 있음.

4. **RAG ↔ LLM Wiki Pattern**: 완전한 sibling/대비 관계. RAG의 parent를 LLM Wiki Pattern으로 잡은 것은 약한 제안. 둘 다 root로 두는 것이 더 적절할 수 있음.
