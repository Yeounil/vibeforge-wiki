# Wiki Typography & Wiki-link Visual Polish — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make `/wiki/*` pages visually polished — tables get borders + accent header, fenced/inline code gets gray boxes, wiki-links render in site purple with dotted underline (distinct from external links and existing broken-link gray strikethrough).

**Architecture:** Single dependency add (`@tailwindcss/typography`) + CSS-only changes in `app/globals.css`. No JS, parser, route, or content changes — the markdown rendering pipeline (`lib/wiki/render.ts`) and alias map (`lib/wiki/backlinks.ts`) already produce semantically correct HTML; the missing piece is the `.prose` typography stylesheet.

**Tech Stack:** Tailwind CSS 4.1 (CSS-first config), `@tailwindcss/typography` plugin (≥0.5.16), existing design tokens in `lib/design/tokens.css`.

**Spec:** `docs/superpowers/specs/2026-05-02-wiki-typography-design.md`

**Branch:** Continue on `plan3/supabase-forum` (current branch). No worktree needed — change is small and isolated to two files.

## Task 2: Apply site-palette overlay to `.prose`

**Files:**
- Modify: `app/globals.css` (append after the `@plugin` directive added in Task 1)

This is a single CSS block touching multiple element classes within `.prose`. We append it as one block and commit once — splitting per-element would create churn without clear value. (Reverting the typography work means reverting this entire block anyway.)

- [ ] **Step 2.1: Append the overlay block**

Open `app/globals.css`. After the `@plugin "@tailwindcss/typography";` line added in Task 1, append:

```css

/* Wiki body typography — bridges typography plugin defaults to site palette.
   Tokens defined in lib/design/tokens.css. */
.prose {
  --tw-prose-body: var(--text-primary);
  --tw-prose-headings: var(--text-primary);
  --tw-prose-links: var(--accent-from);
  --tw-prose-bold: var(--text-primary);
  --tw-prose-code: var(--text-primary);
  --tw-prose-quotes: var(--text-secondary);
}

/* Tables — rounded corners with subtle accent header */
.prose table {
  border-collapse: collapse;
  border-radius: 8px;
  overflow: hidden;
}
.prose thead { background: rgba(124, 58, 237, 0.06); }
.prose th,
.prose td {
  padding: 0.5em 0.75em;
  border-bottom: 1px solid rgba(0, 0, 0, 0.06);
}

/* Inline + fenced code — light gray boxes, no syntax highlighting */
.prose code {
  background: rgba(0, 0, 0, 0.04);
  padding: 0.1em 0.3em;
  border-radius: 4px;
}
.prose pre {
  background: rgba(0, 0, 0, 0.04);
  padding: 1em;
  border-radius: 8px;
}
.prose pre code {
  background: transparent;
  padding: 0;
}

/* Wiki-links — distinct from prose default link color via dotted underline +
   accent color + soft hover background. data-wiki-target is set by
   lib/wiki/render.ts rehypeResolveWikiLinks plugin. Existing
   a[data-broken="true"] rule above gives the third (broken) state. */
.prose a[data-wiki-target] {
  color: var(--accent-from);
  text-decoration: underline dotted;
  text-underline-offset: 0.2em;
  text-decoration-thickness: 1.5px;
}
.prose a[data-wiki-target]:hover {
  background: rgba(124, 58, 237, 0.08);
  border-radius: 3px;
}
```

## Task 4: Fallback path (only if Task 1 fails)

**Skip this task if Task 1 succeeded.** This documents what to do if `@plugin "@tailwindcss/typography";` doesn't activate the prose styles in Tailwind 4.1 (e.g., Step 1.5's visual check shows tables and lists still un-styled).

**Files:**
- Modify: `app/globals.css` (replace the `@plugin` directive with hand-written CSS)
- Modify: `package.json` (remove the typography devDep)

- [ ] **Step 4.1: Uninstall the plugin**

Run:
```bash
npm uninstall @tailwindcss/typography
```

- [ ] **Step 4.2: Replace `@plugin` line with element-selector CSS**

Open `app/globals.css`. Replace the `@plugin "@tailwindcss/typography";` line with:

```css
/* Hand-written prose styles (typography plugin incompatible with Tailwind 4.1).
   Provides minimal but readable markdown rendering. */
.prose {
  color: var(--text-primary);
  line-height: 1.7;
  max-width: 65ch;
}
.prose.max-w-none { max-width: none; }
.prose h1 { font-size: 1.875rem; font-weight: 700; margin: 1.5em 0 0.5em; }
.prose h2 { font-size: 1.5rem; font-weight: 600; margin: 1.5em 0 0.5em; }
.prose h3 { font-size: 1.25rem; font-weight: 600; margin: 1.25em 0 0.5em; }
.prose h4 { font-size: 1.05rem; font-weight: 600; margin: 1em 0 0.5em; }
.prose p { margin: 0.75em 0; }
.prose ul, .prose ol { margin: 0.75em 0; padding-left: 1.5em; }
.prose ul { list-style: disc; }
.prose ol { list-style: decimal; }
.prose li { margin: 0.25em 0; }
.prose blockquote {
  border-left: 3px solid var(--accent-from);
  padding-left: 1em;
  color: var(--text-secondary);
  margin: 1em 0;
}
.prose a { color: var(--accent-from); text-decoration: underline; }
.prose strong { font-weight: 600; color: var(--text-primary); }
```

The Task 2 overlay block (table, code, wiki-link rules) stays in place — those are scoped to `.prose <element>` selectors and work either way.
