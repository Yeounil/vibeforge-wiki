# DM 실습 P-03 — 행렬과 배열

데이터마이닝 강의 (2026 봄학기)의 R 실습 3. [[R]]의 행렬(2차원 배열)과 고차원 배열.

## 1. 배열·행렬이란

- **배열**: 규칙적으로 나열된 데이터 집합. 차원을 가짐.
- **행렬**: 행·열을 추가 속성으로 가진 **벡터** — 2차원 배열이 곧 행렬. 원소는 단일 타입.

## 2. 행렬 생성

### 저장 방식

- R은 **열 우선 배열**(column-major order). 1열 → 2열 → ... 순.

### `matrix()`

```r
m <- matrix(1:6, nrow=2, ncol=3)           # 열 우선
m <- matrix(1:6, nrow=2, byrow=TRUE)       # 행 우선 입력
```

- `nrow`·`ncol` 중 하나만 지정해도 OK.
- 먼저 `y <- matrix(nrow=2, ncol=2)`로 틀 잡고 원소별 할당도 가능.

## 3. 행렬 연산

### 선형대수

- 행렬 간 곱: `%*%`.
- 행렬-상수 곱, 행렬 합: 원소 단위.

### 인덱싱

- 벡터처럼 `m[i, j]`, `m[i, ]`, `m[, j]`.
- 음수 인덱스로 특정 원소 제외.
- 부분행렬에 값 할당 가능.

### 필터링

- 조건 행렬 반환 `m[m > 5]`.
- 특정 행·열에 조건 적용: `m[m[3, ] >= 5]`.

## 4. 행·열에 함수 적용 — `apply()`

```r
apply(m, dimcode, f, flags)
```

- `dimcode=1` — 행에 적용, `2` — 열에 적용.
- 예: `apply(m, 2, mean)` — 각 열 평균.
- 관련 군: `tapply()`, `lapply()` 등.

## 5. 행·열 추가·삭제

- 행렬은 추가/삭제 불가 → **재할당**.
- `rbind(m, new_row)`, `cbind(m, new_col)`.

## 6. 차원과 의도하지 않은 축소

- `dim(m)`, `nrow(m)`, `ncol(m)`.
- 일부 데이터 추출 시 결과가 **벡터로 축소**될 수 있음.
- 방지: `m[, 1, drop=FALSE]` — 습관적으로 사용 권장.
- 벡터 → 행렬: `as.matrix(v)`.

## 7. 행·열 이름

- 인덱스 숫자 대신 이름 부여 가능 → 가독성·분석 시 유용.
- `rownames(m)`, `colnames(m)`.

## 8. 고차원 배열 — `array()`

- 3차원 이상 필요 시 (예: 학생 3명 × 과목 2 × 시험 2회).

```r
array(data, dim=c(학생수, 과목수, 시험수))
```
