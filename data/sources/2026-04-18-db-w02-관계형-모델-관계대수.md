# DB 2주차 — 관계형 데이터 모델 & 관계 대수

DB 강의 (2026 봄학기)의 2주차. 두 강의: ③ 관계형 데이터 모델의 구조·특성 상세, ④ 관계 해석·관계 대수.

## 강의 3 — 관계형 데이터 모델

### 1. 데이터 모델 3요소

| 요소 | 역할 | 예 (정수) |
|---|---|---|
| **구조 (Structure)** | 데이터의 정적 성질. 개체와 관계. | ..., -2, -1, 0, 1, 2, ... |
| **연산 (Operation)** | 데이터의 동적 성질. 조작 방식. | +, -, ×, ÷ |
| **제약조건 (Constraint)** | 논리적 제한. 조작의 한계. | 정수/정수가 정수 아닐 수 있음 |

### 2. 데이터베이스 구성 관점

- **개념적 구조** — 사용자 입장. 개체(Entity) + 관계(Relationship).
- **논리적 구조** — 컴퓨터가 인식하는 데이터 구조. DBMS와 사용자의 공통 인식.
- **물리적 구조** — 저장 미디어 위의 배치·구성. 사용자는 숙지할 필요 없음.

### 3. 개체·속성·관계

- **개체(Entity)** — 표현 대상 객체 (물질적일 필요는 없음; 수강신청·계약도 개체). 파일 시스템의 레코드에 대응.
- **속성(Attribute)** — 데이터의 가장 작은 **논리적** 단위 (물리 단위는 비트).
- **개체 타입 / 개체 집합 / 개체 인스턴스** 구분.
- **관계(Relationship)** — 개체 간 연관 (예: 교수-학생의 지도 관계).

### 4. 데이터 모델 발전

계층 모델 / 네트워크 모델 → **[[관계형 데이터 모델]]** (현재 주류) → 객체지향 모델 → **객체 관계형 모델**(현재 DBMS).

### 5. 관계형 데이터베이스의 장점

1. **단순한 모델 구조**
2. **수학적 강건성** — [[집합론]] 기반 (독일 수학자 **[[Georg Cantor]]**)
3. **SQL** — 간단한 비절차적 언어로 처리

### 6. 군집(Collection) 분류

| | 중복 | 순서 |
|---|---|---|
| **Set** | × | × |
| **Bag** (Multi-Set) | O | × |
| **List** | × | O |
| **Array** | O | O |

### 7. 릴레이션 = 2차원 테이블

[[릴레이션]]은 **튜플들의 집합**. 테이블 한 행 = **튜플(Tuple)**, 한 열 = **속성(Attribute)**.

- **도메인(Domain)** — 속성이 가질 수 있는 값의 집합. "타입과 변수"의 타입에 해당.
- **릴레이션 스키마** — 릴레이션 이름 + 속성 목록 `R(A₁,...,Aₙ)`. 각 Aᵢ는 도메인 Dᵢ에 대응.
- **릴레이션 인스턴스** — 어느 시점의 튜플 집합.
- 수학적 정의: `R ⊆ D₁ × D₂ × ... × Dₙ` (카티션 프로덕트의 부분집합).
- **차수(Degree)** — 속성의 수(열 수).
- **카디널리티(Cardinality)** — 튜플의 수(행 수).

### 8. 릴레이션의 4대 특성

- **튜플의 유일성** — 집합이므로 중복 불가.
- **튜플의 무순서성** — 집합이므로 순서 없음.
- **속성의 무순서성** — 스키마는 속성들의 집합.
- **속성의 원자성(Atomicity)** — 속성 값은 더 쪼갤 수 없는 **원자 값**. 반복 그룹 불허 → **정규화 릴레이션**만 취급.

## 강의 4 — 관계 해석 & 관계 대수

### 1. 해석 vs 대수

| | [[관계 해석]] | [[관계 대수]] |
|---|---|---|
| 명시 | What (선언적) | What + How (절차적) |
| 기반 | 수학의 **술어해석(Predicate Calculus)** | 수학적 **집합 이론** |
| 제안자 | [[E.F. Codd]] | - |
| 예시 언어 | [[SQL]] (튜플 해석), **QBE** (도메인 해석) | 질의 처리·최적화의 내부 기반 |

두 언어의 **표현력(Expression Power)은 동등**.

### 2. 관계 해석의 두 유형

- **튜플 관계 해석** — 변수 범위가 **릴레이션**. 예: `{t | 학생(t) AND t.성적 > 3.5}`. SQL 기반.
- **도메인 관계 해석** — 변수 범위가 **속성 도메인의 값**. QBE 기반.

주요 개념:
- **WFF** (Well Formed Formula)
- **정량자**: 전체(∀, Universal), 존재(∃, Existential)
- **자유 변수** vs **속박 변수**(정량자로 한정됨)

### 3. SQL · QBE

- **SQL** (Structured Query Language) — 튜플 관계 해석 기반. IBM **산호세 연구소** 개발.
- **QBE** (Query By Example) — 도메인 관계 해석 기반. IBM **왓슨 연구소** 1975년 개발. MS-Access가 지원.

### 4. 관계 대수 개요

집합 이론 기반 연산 집합:

**단항 연산자** (릴레이션 1개 입력)
- **셀렉션(Selection)** — 조건 만족 튜플 선택
- **프로젝션(Projection)** — 특정 속성만 선택
- **개명(Rename)**

**이항 연산자** (릴레이션 2개 입력)
- **카티션 프로덕트**
- **조인(Join)**
- **합집합 / 교집합 / 차집합**

### 5. 폐쇄 성질 (Closure Property)

**연산의 입력과 출력이 같은 자료형**(릴레이션).

- 정수 + 정수 = 정수 → 폐쇄 (덧셈은 정수에 대해 폐쇄)
- 정수 ÷ 정수 = 실수 가능 → 비폐쇄

관계 대수의 모든 연산은 **릴레이션 → 릴레이션**이므로 폐쇄. 덕분에 **연산 중첩(Nesting)** 이 자유로움: `σ(π(⋈(R, S)))`.
