# DM 강의 03 — 데이터 탐색과 분석·OLAP

데이터마이닝 강의 (2026 봄학기)의 이론 3강 (2시간). 데이터 사이언스 절차 → 요약 통계 → 시각화 → [[OLAP]]과 다차원 분석.

## 1. 데이터 탐색이란

- 본격 분석 전 **사전 조사**. 요약 통계·시각화·다차원 분석으로 주요 특성을 직관적으로 이해.
- 산출물: (1) 일반 패턴/트렌드, (2) 이상치/비정상 패턴.

## 2. 데이터 사이언스 6단계

1. 프로젝트 목적·문제 정의
2. 데이터 수집/검증/수정
3. 데이터 탐색·전처리
4. 데이터마이닝/ML 모델 구축
5. 결과 평가·해석
6. 적용·모니터링

### 모델 구축 단계별 알고리즘

| 문제 | 알고리즘 |
|---|---|
| 분류 | Logistic regression, kNN, Naïve Bayes, Classification Trees, NN, LDA |
| 예측 (회귀) | Linear regression, kNN, Regression Trees, NN |
| 연관규칙 | [[Apriori]] |
| 군집화 | Hierarchical clustering, k-means clustering |

### 주요 개념

- **독립변수 vs 종속변수** (예: 이탈 예측 — 나이·성별·사용기간 → 이탈 여부).
- **정성적 vs 정량적 변수**: 사칙연산 가능 여부.
- **이상치 vs 결측치**: 값은 존재하되 비현실적 / 값이 아예 없음.
- **[[차원의 저주]]**: 변수↑ → 동일 설명력 유지를 위한 레코드 수가 **기하급수적** 증가.
- **변수 선택 vs 변수 추출**: 원 변수 형태 보존 여부.
- **과적합 (overfitting)**: 필요 없는 특징까지 학습.
- **데이터 분할**: 학습(training) / 검증(validation) / 테스트(test).
- **정규화**: Z-score = (value − mean) / std.

### 성능 평가 지표

- 연관규칙: 지지도 P(A,B), 신뢰도 P(A|B) = P(A,B)/P(B).
- 군집화: 군집 내 분산 작고, 군집 간 분산 큼.

## 3. 아이리스 데이터 집합

- [[아이리스 데이터]] — 150개 꽃 (setosa 50, virginica 50, versicolour 50).
- 속성: sepal length/width, petal length/width + 종.

## 4. 요약 통계

| 통계 | 정의 |
|---|---|
| 빈도 (frequency) | 속성 값의 출현 비율/백분율 |
| 최빈값 (mode) | 가장 빈도 높은 속성 값 |
| 평균 (mean) | 대표값. **이상치에 취약**. |
| 중앙값 (median) | 정렬 후 중앙. 이상치에 강건. |

## 5. 시각화

목적: 많은 데이터 → 직관적 해석 → 패턴·이상치 발견.

| 기술 | 용도 |
|---|---|
| 히스토그램 | 단일 변수의 분포. bin 개수가 중요. |
| 이차원 히스토그램 | 두 속성의 연관 분포. |
| 상자 도표 (box plot) | 단일 속성 분포를 상자 크기로. |
| 산포도 (scatter plot) | 두 속성의 분포·상관관계. |

## 6. [[OLAP]] (Online Analytical Processing)

- 관계형 DB를 제안한 [[E.F. Codd]]이 제안.
- 관계형 DB: 테이블 형태. OLAP: **다차원 배열** 형태.
- 타겟 속성(셀 값) + 축 속성(인덱스) 선정. 속성 수 = 차원.

### OLAP 연산

| 연산 | 의미 |
|---|---|
| 데이터 큐브 (data cube) | 부분집합에 대한 집계 (합계·평균) |
| 슬라이싱 (slicing) | 하나 이상의 축을 중심으로 셀 선택 |
| 다이싱 (dicing) | 셀의 사각 집합 선택 |
| 롤-업 (roll-up) | 작은 단위(day) → 큰 단위(month·year) 집계 |
| 드릴-다운 (drill-down) | 큰 단위 → 작은 단위 분해 |
