# DM 실습 P-04 — 리스트

데이터마이닝 강의 (2026 봄학기)의 R 실습 4. [[R]]의 리스트 — 혼합 타입 컨테이너.

## 1. 리스트란

- 확장된 벡터로서 **어떤 자료형이든** 원소로 올 수 있음.
- 키-값 저장 가능 (C++/Java의 Hash, Python dict 유사).

## 2. 생성

```r
list(a = 1, b = "hello", c = c(1, 2, 3))
vector(mode = "list", length = 3)   # 벡터 함수로도 가능
```

## 3. 인덱싱

### <code>list&#91;&#91;index&#93;&#93;</code> vs <code>list&#91;index&#93;</code>

- <code>list&#91;&#91; &#93;&#93;</code>: 해당 **원소** 반환 (원래 타입).
- `list[ ]`: **리스트 부분집합** 반환 (항상 리스트).
- 키 접근: `list$name` 또는 <code>list&#91;&#91;"name"&#93;&#93;</code>.

## 4. 원소 추가·삭제

```r
z$a <- 1; z$b <- 2        # 생성
z[5:7] <- c(F, T, T)      # 범위로 추가
z$c <- "new"              # 키로 추가
z$b <- NULL               # 삭제 (인덱스 1씩 앞으로)
```

인덱스 위치에 직접 추가도 가능: <code>z&#91;&#91;4&#93;&#93; &lt;- 28</code>.

- 리스트 결합: `c(list1, list2)`.

## 5. 함수 적용

| 함수 | 반환 |
|---|---|
| `lapply(L, f)` | **리스트** |
| `sapply(L, f)` | **벡터 또는 행렬** (simplify) |

## 6. 활용 맥락

- 함수가 **여러 값을 하나로 묶어 반환**할 때 주로 사용.
- 예: `hist(Nile)`은 그래프를 그리면서 breaks·counts·mids 등을 담은 리스트 반환.

## 7. 과제 — `findwords()`

- 어떤 단어가 텍스트 파일에 있는지 판단, 각 단어 **위치 리스트** 생성.
- 힌트
  - 글자 아닌 문자는 공백 처리.
  - 대문자 → 소문자.
  - 파일 읽기: `scan()`.
