# DM 강의 02 — 데이터 종류와 전처리·유사도

데이터마이닝 강의 (2026 봄학기)의 이론 2강 (4시간). 데이터 타입 → 품질·전처리 → [[유사도]]·거리 함수.

## 1. 데이터와 속성

- **데이터 집합**: 객체(레코드·점·엔티티)들의 모임. 각 객체는 **속성**(attribute·변수·필드)으로 기술됨.

### 속성의 4가지 타입

| 타입 | 의미 | 예 |
|---|---|---|
| 명목형 (nominal) | 단순 분류 | ID, 눈 색깔 |
| 서열형 (ordinal) | 이산값 + 순서 관계 | 성적 A+/A/B+, 맛 점수 |
| 구간 (interval) | 차이 의미 있음 | 날짜, 섭씨 온도 |
| 비율 (ratio) | 차이·비율 둘 다 | 질량, 길이, 전류 |

### 이산 vs 연속

- 이산(discrete): 셀 수 있는 값들의 유·무한 집합 (우편번호, 단어 집합). 이진(binary)은 특수 형태.
- 연속(continuous): 실수 값 (온도·키·무게).

### 데이터 집합의 타입

- **레코드 기반**: 데이터 행렬, 문서 데이터, 트랜잭션 데이터.
- **그래프 기반**: WWW, 분자 구조.
- **서열형 (ordered)**: 공간·시간·순차·유전자 시퀀스 데이터.

## 2. 데이터 품질 문제

| 문제 | 설명 |
|---|---|
| 노이즈 (noise) | 원본 값을 변경 (음성 왜곡, TV 흔들림). 임의·예측 불가. |
| 이상치 (outlier) | 다른 객체와 크게 다른 객체. 노이즈와 달리 **분석 대상**이 될 수 있음. |
| 누락 값 (missing) | 수집 실패·적용 불가. 처리: 제거·추정(imputation)·무시·모든 값 대치. |
| 중복 데이터 | 특히 여러 소스 통합 시. → 데이터 정제(data cleaning). |
| 불일치 | 동일 개체에 대한 측정값 상이 (주소 같은데 우편번호 다름). |

## 3. 데이터 전처리 단계

1. **데이터 수집** — 응용에 맞춰 정의.
2. **데이터 정제** — 누락값·잡음 교정, imputation.
3. **데이터 통합** — 여러 DB/파일을 통합.
4. **데이터 축소** — 집계·샘플링·차원축소·특징선택.
5. **데이터 변환** — 정규화·이산화·집계.

### 특징 추출 (feature extraction)

- 센서 데이터 → 웨이블릿·푸리에 변환 → 고수준 특성.
- 이미지 → 픽셀/컬러 히스토그램/시각적 단어 (컨볼루션 NN).
- 문서 → bag-of-words, 불용어 제거.

### 데이터 형식 변환

- **Numeric → Categorical (discretization)**: 숫자 속성을 범위로 분할. Equi-width / Equi-depth / Equi-log 범위.
- **Categorical → Numeric (binarization)**: X개 값 → X개 이진 속성.

### 데이터 축소

- **집계 (aggregation)**: 도시→지역→국가, 날짜→월→년.
- **샘플링**: 교체 없는/있는 샘플링, 편향 샘플링 (시간적 붕괴 편향).
- **특징 선택 (feature selection)**: 관련 없는 특성 제거 (supervised/unsupervised).
- **[[차원의 저주|차원 축소]]**: [[PCA]], SVD.

## 4. 유사도와 거리

### [[유사도|유사도·비유사도]]

- 유사도(similarity): 두 객체가 얼마나 닮았는지 수치.
- 비유사도(dissimilarity) = 거리(distance): 얼마나 다른지.

### Minkowski distance (Lp-norm)

$$L_p(x,y) = \left(\sum_k |x_k - y_k|^p\right)^{1/p}$$

| p | 이름 |
|---|---|
| 1 | Manhattan distance |
| 2 | Euclidean distance |
| ∞ | Supremum distance (Chebyshev) |

### 주요 이슈

- **도메인 관련성**: "급여"가 "성별"보다 신용점수에 중요 → 가중 Lp (상관계수 aᵢ).
- **[[차원의 저주]]**: 차원이 커지면 거리 대비(contrast)가 사라짐 → Lp-norm 효율 감소.
- **데이터 분포**: 분산 방향을 고려해야 함 (마할라노비스 거리로 이어짐).

### 범주형 데이터

- 이진화 후 숫자 알고리즘 적용 가능.
- S(xᵢ, yᵢ) = 1 if xᵢ = yᵢ, else 0.
- **역발생 빈도**(inverse occurrence frequency): 드문 값의 일치에 더 큰 가중치 ("암" 일치가 "정상" 일치보다 유의미).

### 문자열 유사도

- Lp는 문서 길이에 민감 → 긴 문서끼리 거리가 항상 큼.
- **코사인 유사도**: `cos(d₁,d₂) = <d₁,d₂> / (||d₁|| ||d₂||)` — 각도 기반, 절대 길이에 무관.

### 상관관계 (correlation)

- 두 객체/변수의 **선형 관계**. 범위 [-1, 1].
- 1(-1): 완전한 양(음)의 선형 관계. 0: 선형 관계 없음 (비선형 관계는 있을 수 있음, e.g., y = x²).
