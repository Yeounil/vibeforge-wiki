# DB 7주차 — SQL 기초 & DML 실습

DB 강의 (2026 봄학기)의 7주차. ⑬ [[SQL]] 역사·기본 문법·MS-SQL 환경, ⑭ DML 실습(INSERT/UPDATE/DELETE).

## 강의 13 — SQL 기초

### 1. SQL 역사

- **1974** — IBM San Jose Lab(현 Almaden)에서 **SEQUEL** 개발. 최초 관계형 DBMS 프로토타입인 **System R** 용.
- **1986** — ANSI 표준 인증.
- 버전 진화: SQL-86/SQL1 → SQL-92/SQL2 → SQL-99/SQL3 → **SQL-2003/SQL4** (객체 지향 개념 추가).

### 2. SQL 특징

- 종합 데이터베이스 언어 (**DDL + DML + DCL**).
- 비절차적: What만 명시, How는 DBMS가 처리.
- **관계 대수**와의 차이: SQL은 결과가 **Bag(중복 허용)** — 중복 제거가 비용이라 기본은 유지.

### 3. DDL 문법

```sql
-- 테이블 생성
CREATE TABLE 테이블명 (
  속성명 속성타입 [제약조건],
  ...
)

-- 테이블 삭제 (회복 불가)
DROP TABLE 테이블명

-- 내용만 삭제 (테이블 유지)
TRUNCATE TABLE 테이블명

-- 구조 변경
ALTER TABLE 테이블명 ADD 속성명 속성타입
ALTER TABLE 테이블명 DROP 속성명 속성타입
ALTER TABLE 테이블명 ALTER 속성명 속성타입
```

**주의**: `ALTER COLUMN` 으로 타입 범위를 **축소**할 경우 기존 데이터와 충돌하면 거부됨. 확장은 문제없음.

### 4. 제약조건 (5종)

| 제약 | 의미 |
|---|---|
| `NOT NULL` | NULL 불가 |
| `UNIQUE` | 값 중복 불가 (주로 대체키) |
| `PRIMARY KEY` | = UNIQUE + NOT NULL |
| `FOREIGN KEY ... REFERENCES` | 외래키 |
| `CHECK` | 도메인 무결성 — 값 제한 |

명시 방법:
```sql
-- 속성 단위
name varchar(20) NOT NULL
id int CONSTRAINT PK_01 PRIMARY KEY

-- 테이블 단위 (복합키 등)
CREATE TABLE T (
  a int, b int,
  CONSTRAINT pk_ab PRIMARY KEY (a, b)
)

-- FK
부서번호 int CONSTRAINT fk_dept REFERENCES 부서(부서번호)

-- CHECK
birthYear int CHECK (birthYear >= 1900)
Age int CHECK (Age BETWEEN 1 AND 150)

-- 추후 변경
ALTER TABLE T ADD CONSTRAINT ...
ALTER TABLE T DROP CONSTRAINT 제약조건명
```

### 5. MS-SQL 환경 (실습)

- **MS-SQL Server 2014 Express** 사용 (Express/Workgroup/Standard/Enterprise 4 에디션).
- T-SQL = MS-SQL Server에서 쓰는 SQL.
- 설치 파일: `SQLEXPRWT_x64_KOR.exe` (64bit).
- SSMS(SQL Server Management Studio)로 접속.

시스템 DB:
- **master** — 시스템 관리용
- **model** — 신규 DB 생성 템플릿
- **msdb** — SQL Server Agent
- **tempdb** — 질의 임시 결과

사용자 DB 생성:
```sql
USE master
CREATE DATABASE test01
```

### 6. 주요 데이터 타입

**숫자**
- `bit` (1bit), `tinyint`, `smallint`, `int`, `bigint`
- `decimal(p, s)`, `numeric`, `float`, `real`

**날짜**
- `datetime`, `smalldatetime`

**문자**
- `char(n)`, `varchar(n)` (ASCII)
- `nchar(n)`, `nvarchar(n)` (유니코드, 2byte/char)

**자동 증가**
- `IDENTITY(시작값, 증가값)` — 예: `IDENTITY(10, 2)` → 10, 12, 14, ...

## 강의 14 — DML 실습

### 1. INSERT — 데이터 삽입

**단일 행 삽입**:
```sql
INSERT INTO 테이블명 (속성명, ...) VALUES (값, ...)
-- 속성명 생략 시 테이블 정의 순서대로 입력
```

**NULL 입력**:
- 묵시적: 속성명에서 생략
- 명시적: `VALUES (..., NULL, ...)`
- `NOT NULL` 제약 있으면 입력 불가.

**서브쿼리로 다중 행 삽입**:
```sql
INSERT INTO EMPTEST
SELECT * FROM 사원 WHERE 부서번호 = 30
```

**다중 행 VALUES** (MS-SQL 2008+):
```sql
INSERT INTO t VALUES (값1), (값2), (값3)
```

**질의 결과로 테이블 생성**:
```sql
-- MS-SQL: SELECT ~ INTO
SELECT 컬럼리스트 INTO 대상테이블
FROM 테이블 WHERE 조건

-- 오라클: CREATE ~ AS SELECT
CREATE TABLE 대상테이블 AS
SELECT 컬럼리스트 FROM 테이블 [WHERE 조건]
```

결과 테이블은 기존 속성명·타입·`NOT NULL`을 그대로 적용 (다른 제약조건은 적용 안 됨).

**구조만 복사** (튜플 제외): `WHERE 1 > 2` 등 **항상 거짓** 조건 활용.

### 2. UPDATE — 데이터 갱신

```sql
UPDATE 테이블명 SET 속성 = 값 [, ...] [WHERE 조건]
```

**WHERE 생략 시 전체 행 갱신** — 주의.

**서브쿼리 활용**:
```sql
UPDATE 테이블 SET 속성 = (SELECT ~ FROM ~ WHERE ~)
WHERE 조건
```

다중 속성 동시 갱신:
```sql
UPDATE EMPTEST SET Salary = 300, Commission = 50 WHERE eno = 51
```

### 3. DELETE — 데이터 삭제

```sql
DELETE [FROM] 테이블 [WHERE 조건]
```

**WHERE 생략 시 전체 행 삭제** — 주의.

**서브쿼리 활용**:
```sql
DELETE FROM EMPTEST
WHERE 부서번호 IN (SELECT 부서번호 FROM 부서 WHERE 부서명 = 'Accounting')
```

### 4. 테이블 구조 조회

- **오라클**: `DESCRIBE 테이블명` (or `DESC`)
- **MS-SQL**: `EXEC sp_help 테이블명`

## 핵심 용어

| 용어 | 정의 |
|---|---|
| DDL | 구조 정의: CREATE·DROP·ALTER·TRUNCATE |
| [[DML]] | 조작: INSERT·UPDATE·DELETE·SELECT |
| DCL | 제어: GRANT·REVOKE·COMMIT·ROLLBACK |
| 제약조건 | NOT NULL, UNIQUE, PK, FK, CHECK |
| SELECT ~ INTO | 질의 결과로 새 테이블 생성 (MS-SQL) |
| 서브쿼리 | INSERT·UPDATE·DELETE 내부에서 SELECT 활용 |
