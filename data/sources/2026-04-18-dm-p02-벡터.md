# DM 실습 P-02 — 벡터

데이터마이닝 강의 (2026 봄학기)의 R 실습 2. [[R]]의 핵심 데이터 타입 벡터.

## 1. 벡터란

- [[R]]의 기본 데이터 타입. "숫자 값"은 존재하지 않음 — 길이 1 벡터.

## 2. 선언

- 선언 불필요 (Python 유사): `z <- 3` (길이 1 벡터 할당).
- 다중 원소: `c(10, 20, 30)`.

## 3. 원소 추가·삭제

- 벡터는 **크기 불변** — 처음 만들 때 결정.
- 추가/삭제는 **새 벡터 재할당** (R 성능 제약 요인 중 하나).
- 중간 삽입: `c(head, new, tail)`.

## 4. 벡터 연산

### 길이

```r
length(x)
```

### 재사용 (recycling)

- 두 벡터 연산 시 길이가 다르면 **짧은 쪽이 재사용**되어 긴 쪽에 맞춰짐.

### 원소 단위 산술·논리

- 산술·논리 연산자도 실제는 함수 → 원소 단위 수행.

### 인덱싱

| 형태 | 의미 |
|---|---|
| `v1[v2]` | v1에서 v2 인덱스 해당 원소 |
| `v[-i]` | i번째 **제거** 후 반환 |
| `v[2:5]` | 범위 |

### 콜론 연산자 `:`

- `1:10` — 1~10 벡터 생성.
- **산술 연산자보다 우선순위 높음** (주의).
- 전체 우선순위: `?Syntax`.

### `seq()` — 범위 생성

- `seq(1, 10, by=2)`, `seq(from, to, length.out=n)`.
- 빈 벡터 처리에 유용 (`seq_along(x)`).

### `rep()` — 반복

- `rep(x, times=n)`: 전체를 n회.
- `rep(x, each=n)`: 각 원소를 n회.

### `all()` / `any()`

- `all(x > 0)`: 모두 참?
- `any(x > 0)`: 하나라도 참?

### 벡터화 연산

- 벡터에 함수 적용 → 내부 원소 각각에 적용.
- `>`, `<` 등 비교도 벡터화.

## 5. NA와 NULL

| | 의미 | 용도 |
|---|---|---|
| `NA` | 불확실한 값 (존재함) | 통계 함수에서 skip 옵션 |
| `NULL` | 없음·답 없음 | 반복 빌드에 사용 |

## 6. 필터링

### 조건 기반

```r
z[z*z > 8]    # NA 포함 시 그대로 출력됨
```

### `subset()`

- NA를 자동으로 **제외**. NA 회피 시 선호.

### `which()`

- 조건 만족하는 **위치(인덱스)** 반환.

## 7. 벡터화된 조건문: `ifelse(b, u, v)`

- 벡터화된 if. b[i] == TRUE면 u[i], 아니면 v[i].

## 8. 원소의 이름

- `names(v) <- c("a", "b", "c")` — 이름 지정 후 `v["a"]` 인덱싱 가능.
- `names(v) <- NULL` — 이름 제거.

## 9. 실전 예제: 기상 데이터 예측

- 과제: 지난 k일로 내일 비 예측 (다수결).
- 전략: 누적합(`cumsum`)으로 윈도우 합을 O(1) 계산.

```r
predict <- function(x, k) {
  n  <- length(x)
  k2 <- k/2
  pred <- vector(length = n-k)
  csx  <- c(0, cumsum(x))
  for (i in 1:(n-k)) {
    pred[i] <- ifelse(csx[i+k] - csx[i] >= k2, 1, 0)
  }
  return(mean(abs(pred - x[(k+1):n])))  # 오차율
}
```

- 함수형 사고: `cumsum`·`ifelse`·`mean`·`abs` 조합으로 루프 한 번에 해결.
