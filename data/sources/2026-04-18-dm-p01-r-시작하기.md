# DM 실습 P-01 — R 시작하기

데이터마이닝 강의 (2026 봄학기)의 R 실습 1. [[R]] 언어 기본 사용법·함수 정의·데이터 구조 개괄.

## 1. R의 사용 방식

| 모드 | 특징 |
|---|---|
| 인터랙티브 (interactive) | 명령어 입력 → 즉시 결과. **주로 사용**. |
| 배치 (batch) | 소스 코드 일괄 처리. 주석 `#`. |

## 2. 값 할당 & c()

- 할당: `<-` (다른 언어의 `=`와 유사).
- `c()`: 데이터(벡터)들을 **연결**. `c(1, 2, 3)`, 다른 벡터 포함 가능.

## 3. 인덱싱 & 그래프

- 인덱스는 **1부터 시작** (C/Python과 다름).
- 콜론 `:`으로 범위 지정: `x[1:3]`.
- 내장 데이터셋: `data()`.
- 히스토그램: `hist(Nile)` (내장 나일강 데이터).

## 4. 함수 정의

```r
oddcount <- function(x) {
  k <- 0
  for (n in x) {
    if (n %% 2 == 1) k <- k + 1
  }
  return(k)
}
```

- `%%`: 모듈로 (나머지).
- `return()` 생략 가능 — 마지막 식 값이 반환.

### 변수 범위

- **지역**: 함수 본문 내 (호출 후 사라짐).
- **전역**: 함수 밖.

### 기본 인수

- `g <- function(x, y=2, z=T)` → `g(12, z=FALSE)` → x=12, y=2, z=FALSE.

## 5. R 데이터 구조 개괄

| 구조 | 특징 |
|---|---|
| **벡터** | 핵심 구조. 원소는 **같은 타입**. 스칼라도 실제는 길이 1 벡터. 자세히: [[2026-04-18-dm-p02-벡터]] |
| **행렬** | 행·열을 가진 벡터. `rbind()`, `cbind()`, 곱 `%*%`. 자세히: [[2026-04-18-dm-p03-행렬-배열]] |
| **리스트** | 여러 타입 혼합 (C 구조체·Python dict 유사). `$` 기호로 접근. 자세히: [[2026-04-18-dm-p04-리스트]] |
| **[[데이터 프레임]]** | 리스트인데 각 구성요소가 벡터. 파일/DB에서 데이터셋 읽기. 자세히: [[2026-04-18-dm-p05-데이터프레임]] |

### 문자열

- 단일 원소의 문자 벡터.
- `length()`: 길이, `mode()`: 데이터 형.

## 6. 도움말

| 함수 | 용도 |
|---|---|
| `help(seq)` / `?seq` | 온라인 도움말 |
| `?"<"` | 특수문자는 따옴표 |
| `example(seq)` | 예제 실행 |
| `help.search("multivariate normal")` | 구글식 검색 → `mvrnorm` (MASS 패키지) |
