# DB 3주차 — 관계 연산자 & 조인

DB 강의 (2026 봄학기)의 3주차. ⑤ 관계 연산자 상세, ⑥ 조인·확장된 관계 연산자.

## 강의 5 — 관계 연산자

### 1. 일반 집합 연산자 (합·교·차·카티션 곱)

[[릴레이션]]은 튜플들의 집합 → 집합 연산자 적용 가능.

| 연산자 | 기호 | 의미 | 카디널리티 경계 |
|---|---|---|---|
| 합집합 | `R ∪ S` | R 또는 S에 속한 튜플 | `max(|R|,|S|) ≤ |R∪S| ≤ |R|+|S|` |
| 교집합 | `R ∩ S` | R과 S 공통 튜플 | `0 ≤ |R∩S| ≤ min(|R|,|S|)` |
| 차집합 | `R − S` | R엔 있고 S엔 없음 | `0 ≤ |R−S| ≤ |R|` |
| 카티션 곱 | `R × S` | 모든 가능한 튜플 쌍 | `|R × S| = |R| × |S|` |

**법칙**:
- 합집합·교집합 — 교환·결합 법칙 성립
- 차집합 — 교환 법칙 **불성립** (`R − S ≠ S − R`)
- `R ∩ S = R ∪ S − (R−S) − (S−R)` (합성 가능)

### 2. 합병 호환성 (∪·∩·− 피연산자 제약)

1. **차수(Degree)** 가 같아야 함
2. 대응 속성의 **타입(도메인)** 이 같아야 함
3. 대응 속성의 **의미(Semantic)** 가 같아야 함

1·2는 시스템이 검증, 3은 **사람이 책임** (예: `몸무게 ∪ 키` — 타입 맞지만 의미 없음).

카티션 곱은 이 제약 없음.

### 3. 순수 관계 연산자 (2차원 테이블 형식)

#### 셀렉션 (Selection, σ)

- 일항 연산, **조건 만족 튜플만** 선택 (행 필터).
- 표기: `σ<선택조건>(R)`
- 차수 동일, `0 ≤ |σ(R)| ≤ |R|`
- **교환 법칙 성립** — `σ_c1(σ_c2(R)) = σ_c2(σ_c1(R))`
- **선택율(Selectivity)** 낮은 조건을 먼저 수행 → 최적화.

#### 프로젝션 (Projection, π)

- 일항 연산, **특정 속성만** 선택 (열 추출).
- 표기: `π<속성리스트>(R)`
- 폐쇄성·집합 성질 때문에 중복 튜플 제거 → `|π(R)| ≤ |R|`
- **교환 법칙 불성립**

#### 디비전 (Division, ÷)

- 이항 연산, 제약: `S의 속성 ⊆ R의 속성`.
- 의미: **S의 모든 튜플과 연관된 R 튜플**. "모든 ~에 대한" 질의.
- SQL은 직접 지원하지 않음.

#### 개명 (Rename, ρ)

- 중간 결과 릴레이션·속성에 이름 부여.
- 표기: `ρ_S(E)`, `ρ_S(B1,...,Bn)(E)`

#### 집단 연산자 (Aggregation, ℱ) — 확장

- 기본 관계 연산 외에 추가됨.
- `ℱ_<집단함수리스트>(R)` — SUM, MAX, MIN, AVG, COUNT 등.
- 그룹별: `<그룹화속성>ℱ<함수>(R)` (예: 학년별 평균 성적 `year ℱ AVG(score)(STUDENT)`)

## 강의 6 — 조인 & 확장된 연산자

### 1. [[조인 연산자]] 개요

- 이항 연산, 두 [[릴레이션]] 결합.
- 표기: `R ⋈<조인조건> S`
- **조인 속성(Join Attribute)**: R.A, S.B
- 결과 차수 = `R의 차수 + S의 차수`

### 2. 조인 유형

| 유형 | 기호 | 특징 |
|---|---|---|
| **θ 조인** | `R ⋈_{AθB} S` | 일반 비교 연산자(θ = `=, >, <, ≥, ≤, ≠`) |
| **동등 조인(Equijoin)** | `R ⋈_{A=B} S` | θ = `=` |
| **자연 조인(Natural Join)** | `R ⋈_N S` | 공통 속성에 대한 동등 조인, **중복 속성 1회만** 표현. 조인 조건 생략. |

### 3. 근원 연산 vs 복합 연산

**근원 연산 (Primitive, 5개)**: 합집합·차집합·카티션 곱·프로젝트·셀렉트. 이 5개로 대부분의 관계 대수 표현 가능.

**복합 연산 (Composite)**: 교집합, 조인, 디비전. 예:
- `R ⋈_{AθB} S = σ_{AθB}(R × S)`
- `R ∩ S = R − (R − S)`

표현력 자체는 유지되나 **표현 편의성** 증가.

### 4. 세미 조인 (Semi Join, ⋉)

- `R ⋉ S` — R의 튜플 중 S와 자연 조인 가능한 것만.
- **분산 DB에서** 네트워크 부담 최소화에 유용.

### 5. 외부 조인 (Outer Join)

조인 조건 불만족 튜플도 결과에 포함 (누락된 속성은 **NULL**).

- **왼쪽 외부 조인** — R₁의 모든 튜플 포함
- **오른쪽 외부 조인** — R₂의 모든 튜플 포함
- **완전 외부 조인** — 양쪽 모두 포함

### 6. 외부 합집합 (Outer Union, U⁺)

합병 호환성을 만족하지 않는 두 릴레이션 합집합용. 모든 속성을 포함하는 확장 릴레이션으로 만들고 값 없는 자리는 **NULL**.

## 핵심 용어

| 용어 | 정의 |
|---|---|
| 합병 호환성 | 차수·타입·의미 일치 (∪·∩·−의 전제) |
| 선택율 | σ 결과 튜플 비율. 낮은 것부터 적용 → 최적화 |
| 조인 속성 | 조인 조건에 참여하는 속성 쌍 |
| 자연 조인 | 공통 속성 동등 조인, 중복 제거 |
| 세미 조인 | 분산 환경 네트워크 최소화 |
| 외부 조인 | 불일치 튜플도 NULL 채워서 포함 |
| 집단 연산자 | SUM·AVG·MAX·MIN·COUNT |
| 근원 연산 5개 | σ, π, ∪, −, × |
