# DM 강의 04 — 연관규칙 마이닝

데이터마이닝 강의 (2026 봄학기)의 이론 4강 (4시간). 이번 강의의 핵심. 장바구니 분석 → 빈발 항목집합 → [[Apriori]] → [[FP-Growth]] → 규칙 평가 → 범주형·연속형 확장까지.

## 1. 연관규칙이란

- **[[연관규칙마이닝]]** (ARM): 트랜잭션 집합에서 "어떤 아이템이 나타나면 다른 아이템도 함께 나타난다"는 규칙을 찾음.
- 대표 응용: **[[장바구니 분석]]** (market basket analysis).
  - `{Diaper} → {Beer}`, `{Milk, Bread} → {Eggs, Coke}` 등.

## 2. 핵심 개념

### 항목집합 (itemset)

- k-항목집합: k개 항목의 집합.
- **지지도 카운트** σ(X): X가 포함된 트랜잭션 수.
- **지지도** s(X): σ(X) / |트랜잭션 수|.
- **[[빈발 항목집합]]**: s ≥ minsup인 항목집합.

### 연관규칙 X → Y

- **지지도** s: P(X, Y) — 규칙이 얼마나 중요·유용한가.
- **신뢰도** c: P(Y|X) = support(X∪Y) / support(X) — 규칙이 얼마나 믿을만한가.
- 동일 항목집합에서 나온 규칙들은 **지지도는 같지만 신뢰도는 다를 수 있음** → 지지도와 신뢰도 단계 분리.

## 3. 연관규칙 마이닝 2단계

1. **빈발 항목집합 생성** (minsup 만족)
2. **규칙 생성** (minconf 만족)

- 주먹구구(brute force): d개 항목 → 2^d개 항목집합 → 너무 비쌈.

## 4. [[Apriori]] 알고리즘

### Apriori 원리

> **어떤 항목집합이 빈발하다면, 모든 부분집합도 빈발하다.**
>
> 역으로, 부분집합이 빈발하지 않으면 상위집합도 빈발할 수 없음 (**anti-monotone**).

### Pseudo-code

```
L₁ = {빈발 1-항목집합}
for k = 1, L_k != ∅, k++:
    C_{k+1} = L_k × L_k (join & prune)
    각 트랜잭션 t에 대해 C_{k+1} 중 t에 포함된 후보의 카운트 증가
    L_{k+1} = C_{k+1} 중 minsup 만족
return ∪ L_k
```

- **Join**: Lk끼리 셀프조인 → Ck+1.
- **Prune**: Ck+1의 모든 (k)-부분집합이 Lk에 있어야 함.

### 효율 개선

| 기법 | 아이디어 |
|---|---|
| Hash-based counting | 해시 버킷 카운트 < minsup → k-항목집합 빈발 불가 |
| Transaction reduction | 빈발 k-항목집합을 포함하지 않는 트랜잭션 제거 |
| Partition | DB 분할. 전체 빈발 항목집합은 적어도 한 파티션에서 빈발 |
| Sampling | 부분집합에서 먼저 마이닝 |
| Dynamic itemset counting | 부분 항목집합이 모두 빈발 추정될 때만 후보 추가 |
| AprioriTid | 첫 반복 이후 원본 DB 대신 Ck' 사용 |

### 계산 복잡도에 영향

- minsup 낮음 → 빈발 항목집합 수·길이 증가.
- 차원·DB 크기·평균 트랜잭션 길이에 비례.

## 5. 최대 vs 닫힌 빈발 항목집합

| 구분 | 정의 |
|---|---|
| **최대 빈발** (maximal) | 직접 모집합 모두 비빈발. 긴 패턴 생성에 유용. |
| **닫힌 빈발** (closed) | 모든 직접 모집합의 지지도가 **다름**. 지지도 정보 보존. |

포함 관계: Maximal ⊆ Closed ⊆ Frequent.

## 6. [[FP-Growth]] — 후보 없는 마이닝

- Apriori 병목: 후보가 너무 많음(10⁴ 빈발 1 → 10⁷ 후보 2), DB 스캔 n+1회.
- **FP-Growth**: DB를 **FP-Tree**로 압축, 스캔 2회.
- 분할정복 방식, 후보 생성 없음.

### FP-Tree 생성

1. DB 스캔 → 빈발 1-항목집합 추출.
2. 각 트랜잭션의 항목을 빈도순 정렬.
3. DB 재스캔 → FP-Tree 구축 (prefix 공유).

### 조건부 패턴 기반

- 마지막 항목 p부터 시작, 노드 포인터 따라가며 p를 포함한 경로 수집 → 조건부 FP-Tree 구축 → 재귀 마이닝.
- 예: m-conditional pattern base = {(fca:2), (fcab:1)} → m-conditional FP-tree (fca:3) → 모든 m 포함 빈발: m, fm, cm, am, fcm, fam, cam, fcam.

### FP-Tree 장점

- **완전성**: 긴 패턴 보존.
- **간결성**: 빈도순 정렬 → 공유율↑, 불필요 항목 제거.

## 7. Eclat (수직 레이아웃)

- 각 1-항목집합에 **TID 리스트** 저장.
- k-항목집합 지지도 = 두 (k-1)-항목집합 TID 리스트의 **교집합**.
- 장점: 지지도 계산 빠름. 단점: 중간 결과 크기.

## 8. 항목집합 격자 순회 전략

- General-to-specific vs Specific-to-general vs Bidirectional.
- Prefix tree vs Suffix tree (Equivalent classes).
- Breadth-first vs Depth-first.

## 9. 규칙 평가 (유용성 척도)

- ARM은 규칙을 **많이** 생성 → 대부분 중복/무의미 → 유용성 척도로 필터링.

### 신뢰도의 함정

| | Coffee | ¬Coffee | |
|---|---|---|---|
| Coke | 15 | 5 | 20 |
| ¬Coke | 75 | 5 | 80 |
| | 90 | 10 | 100 |

- `Coke → Coffee`: 신뢰도 0.75 (높아 보임).
- 그러나 P(Coffee) = 0.9, P(Coffee | ¬Coke) = 0.9375 → **Coke는 오히려 Coffee를 줄임**.

### Lift (Interest)

$$\text{Lift}(X \to Y) = \frac{\text{conf}(X \to Y)}{\text{support}(Y)} = \frac{P(X,Y)}{P(X)P(Y)}$$

- Lift > 1 → 양의 상관.
- Lift = 1 → 독립.
- Lift < 1 → 음의 상관.
- 예제: `Coke → Coffee`의 Lift = 0.75/0.9 = 0.833 → **음의 연관**.

### 확률적 독립성

- P(S∧B) = P(S)·P(B) → 독립.
- `>` → positively correlated, `<` → negatively correlated.

## 10. 범주형·연속형 속성

### 범주형

- 이진화 (browser = IE/Mozilla/Firefox 각각 이진 속성).
- 이슈:
  - 값 종류가 많을 때 (국가 200+) → 낮은 지지도 집계.
  - 분포가 쏠려 있을 때 (buy=no 95%) → 너무 빈발한 항목 제외.

### 연속형

- 이산화 기반 (unsupervised/supervised).
- 통계 기반 (결론부가 통계량).

## 11. 다단계 연관규칙

- 항목에 계층 구조 (Food > milk > full fat milk > Fraser).
- 낮은 레벨일수록 낮은 지지도.
- Top-down progressive deepening: 고수준 → 저수준.
- 변종: level-crossed, multiple alternative hierarchies.
