# DM 강의 01 — 데이터마이닝 개요

데이터마이닝 강의 (2026 봄학기)의 이론 1강 (2시간). 데이터마이닝의 목적·정의·기술 분류·응용 사례 개괄.

## 1. 왜 데이터마이닝인가

- 데이터는 GB-TB/hour 속도로 축적됨 (WALMART 20M 트랜잭션/일, AT&T 300M 콜/일, MOBIL 100TB 지질 DB).
- 기존 기술(기계학습·통계)은 **엄청난 양**, **고차원**, **이기종·분산** 데이터에 부적합.
- 기업은 데이터 분석을 통해 경쟁력·고객 중심 서비스를 추구.

## 2. 데이터마이닝의 정의

> 대규모 데이터에서 **숨겨져 있으나 잠재적으로 유용한 정보**를 추출하는 작업. 의미 있는 패턴을 자동/반자동으로 탐사·분석.

- 출발 분야: 기계학습·인공지능·패턴인식·통계·DB 시스템.
- 단순 질의·검색은 데이터마이닝이 **아님** (예: 우편번호 조회 X, 문서를 주제별로 그룹핑 O).

## 3. 데이터마이닝 기술 분류

### 예측 방법 (predictive)

| 기술 | 목적 |
|---|---|
| [[분류]] (classification) | 미리 정의된 클래스 중 하나를 레코드에 부여 |
| [[회귀분석]] (regression) | 연속값 변수의 미래 값을 예측 |
| [[이상치 탐색]] (outlier detection) | 정상 행위와 크게 다른 객체 검출 |

### 서술 방법 (descriptive)

| 기술 | 목적 |
|---|---|
| [[클러스터링]] (clustering) | 유사한 데이터 포인트를 그룹핑 |
| [[연관규칙마이닝]] (association rules) | "A를 사면 B도 산다" 형태의 규칙 추출 |
| [[순차패턴]] (sequential pattern) | 시간 순서를 가진 이벤트 간 의존 규칙 |

## 4. 응용 사례

- **[[연관규칙마이닝|연관규칙]]**: [[장바구니 분석]] ({Diaper, Milk} → {Beer}), 마케팅, 마트 진열대 관리, 재고 관리(AS 부품 배달).
- **[[분류]]**: 우편 마케팅(buy/don't buy), 신용카드 사기 적발(평소와 다른 시간·장소), 이탈 고객 예측.
- **[[클러스터링]]**: 시장 세분화(market segmentation), 문서 클러스터링(LA Times 3204 기사), 주식 동향 분석.
- **[[이상치 탐색]]**: 신용카드 사기, 네트워크 침입 탐지.

## 5. Data Mining 이슈

- 확장성 (scalability)
- 차원성 (dimensionality) — [[차원의 저주]]
- 데이터 복잡성·이기종성
- 데이터 품질
- 데이터 소유권·분산
- 개인정보 보호
- 스트리밍 데이터

## 6. 분류 예제 (Refund/Marital/Income → Cheat)

- **훈련 집합**(training set): 분류 모델을 만드는 레코드들.
- **테스트 집합**(test set): 모델의 정확성을 판별하는 레코드들.
- 일정 수준 정확성이 확보되면 모델로서 의미를 가짐 → 미분류 레코드에 클래스 부여.
