# DM 실습 P-05 — 데이터 프레임

데이터마이닝 강의 (2026 봄학기)의 R 실습 5. [[R]]의 [[데이터 프레임]] — 실전 데이터셋 처리의 주 구조.

## 1. 데이터 프레임이란

- 직관적으로는 2차원 (행·열) — 행렬과 유사.
- 차이: **각 열이 다른 타입** 가능.
  - 예: Name(문자) / Salary(정수) / Union(논리).
- 내부적으로는 **리스트** (각 구성요소가 벡터).

## 2. 생성

```r
d <- data.frame(
  kids   = c("Jack", "Jill"),
  ages   = c(12, 10),
  stringsAsFactors = FALSE
)
```

- `stringsAsFactors`: 문자열을 팩터로 변환할지. 기본 TRUE — **팩터 원치 않으면 FALSE**.

### 파일로부터

```r
d <- read.table("file.txt", header = TRUE)
```

## 3. 접근

### 리스트 방식 (권장)

- `d$kids` — **명확**하고 안전.
- <code>d&#91;&#91;"kids"&#93;&#93;</code> — 동등.

### 행렬 방식

- `d[i, j]`, `d[, 1]`.
- **주의**: 한 열만 추출하면 **벡터로 축소** → `d[, 1, drop = FALSE]`.

### 필터링

- 행렬과 유사: `d[d$exam1 >= 3.0, ]`.

### NA 처리

- `complete.cases(d)` — NA 없는 행을 TRUE로.
- `d[complete.cases(d), ]` — NA 있는 행 제거.

## 4. 행·열 추가

- `rbind(d, new_row)`, `cbind(d, new_col)`.

## 5. 데이터 프레임 결합 — `merge()`

- 두 DF를 **공통 변수 값**으로 결합 → 관계형 DB의 **조인**과 유사.
- `merge(d1, d2, by = "id")`.
- 이름이 다르면: `merge(d1, d2, by.x = "id1", by.y = "id2")`.
- **중복**된 키로 결합 시 카테시안 곱 → 신중히 결정.

## 6. 함수 적용

- 리스트처럼 `lapply(d, f)` → 결과는 리스트.
- 다시 DF로: `as.data.frame(result)`.
- **주의**: 정렬·변환 시 행 관계가 깨질 수 있음 → `order()` 권장.
