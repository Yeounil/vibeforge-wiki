# Obsidian

Local-first markdown note-taking app with bidirectional wikilinks, a graph view, and a plugin ecosystem. In the [[LLM Wiki Pattern]] this vault is built on Obsidian — the LLM writes the markdown, Obsidian visualizes it.

## Role in This Vault

- **Reading surface** for the wiki — graph view, backlinks, file tree.
- **Obsidian Web Clipper** (browser extension) — captures articles to `raw/articles/` as markdown.
- **Plugins used / planned**
  - Dataview — frontmatter queries (e.g. area filtering).
  - Marp — generate slide decks from markdown.
- **Image handling** — set *Attachment folder path* to `raw/assets/` and bind *Download attachments for current file* to a hotkey so clipped articles get local images the LLM can view.
