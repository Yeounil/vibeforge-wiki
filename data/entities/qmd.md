# qmd

A local search engine for markdown files. Hybrid BM25 + vector search with LLM re-ranking, all on-device. Ships with both a CLI (agents can shell out) and an MCP server (native tool use).

## Role in LLM Wikis

At small scale (~100 sources), an `index.md` catalog is enough for navigation. As the wiki grows, proper search becomes worth installing. qmd is a drop-in option. **Not yet installed in this vault.**
