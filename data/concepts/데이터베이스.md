# 데이터베이스

한 조직의 다양한 응용 프로그램이 공동으로 사용하기 위해 통합 저장한 **운영 데이터의 집합**.

## 4가지 성격

- **공용(Shared)** — 여러 사용자·부서가 서로 다른 목적으로 공유.
- **통합(Integrated)** — 중복 최소화, 통제된 중복.
- **저장(Stored)** — 컴퓨터가 접근 가능한 매체에 저장.
- **운영(Operational)** — 조직 운영에 필수인 데이터.

## 동작 특징

- 실시간 접근성 — 질의에 즉시 응답
- 계속적 변화 — 현실 세계 반영으로 상태가 동적
- 내용에 의한 참조 — 주소가 아닌 값으로 검색
- 동시 공용 — 여러 사용자 동시 접근

## 파일 시스템과의 비교

파일 시스템은 응용별 파일을 따로 관리 → 중복·비일관성·데이터 고립·무결성 위반·종속성 문제. 데이터베이스는 [[DBMS]] 위에서 통합·표준화로 해결.

## 장단점

**장점**: 중복 최소화, 일관성, 공용, 무결성, 보안, 표준화, 전체 데이터 요구 조정.
**단점**: 운영비 오버헤드, 자료처리 복잡성, 백업/회복 어려움, 시스템 취약성.
