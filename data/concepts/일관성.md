# 일관성

분산 시스템에서 여러 노드에 데이터가 복제·분산되어 있더라도 모든 노드가 항상 동일한 상태·데이터를 참조하도록 보장하는 속성. [[CAP 정리]]의 C.

## 강한 일관성 (Strong Consistency)

쓰기 작업 후 모든 읽기가 항상 최신 값을 반환. 엄격한 동기화, 선형(Linearizable) 상태 보장.
- 구현: 직렬 동기 쓰기 — 모든 레플리카 완료 확인 후 응답
- 지연 시간 증가 대가로 데이터 정합성 최고

## 최종 일관성 (Eventual Consistency)

일시적 불일치를 허용하되, 시간이 지나면 모든 노드가 동일 상태로 수렴. 비동기 복제로 성능과 [[가용성]] 우선.

### 충돌 해결 기법

- **LWW (Last Write Wins)**: 타임스탬프가 늦은 쪽으로 덮어쓰기
- **Vector Clocks**: 작업 이력 추적 후 병합(Merge) — 충돌 없이 두 변경사항 모두 보존
- **가십 프로토콜(Gossip Protocol)**: 중앙 없이 무작위 이웃 노드 간 상태 정보 교환으로 정보 전파

## 쿼럼 읽기 (Quorum Read)

$W + R > N$ 조건 — 쓰기 노드 수 + 읽기 노드 수 > 전체 레플리카 수로 설정하면, 항상 최신 데이터를 가진 노드가 최소 1개 포함됨. 속도와 정확성의 타협점.

## 강한 일관성 vs 최종 일관성

| | 강한 일관성 | 최종 일관성 |
|--|---|---|
| 데이터 정합성 | 즉각 보장 | 결국 수렴 |
| 지연 시간 | 높음 | 낮음 |
| 가용성 | 낮을 수 있음 | 높음 |
| 적합 | 금융 트랜잭션 | SNS, DNS |
