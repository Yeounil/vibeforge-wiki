# 동기화

**동시 실행되는 프로세스·스레드들이 공유 자원에 접근할 때 충돌·race condition을 방지하고 올바른 순서를 보장하는 메커니즘**. Asynchronous + Concurrent 환경의 핵심 문제.

## 핵심 포인트

### 기본 용어
- **Race condition**: 실행 순서에 따라 결과가 달라지는 상태.
- **Critical Section (CS)**: 공유 자원 접근 코드 영역.
- **Mutual Exclusion (ME) 3요건**: ME·Progress·Bounded waiting.

### 해결 4계층

| 계층 | 기법 |
|---|---|
| **SW** | Dekker·Peterson·[[Edsger Dijkstra]]·Knuth·Lamport·Brinch Hansen |
| **HW** | TAS (Test-And-Set), atomic instruction |
| **OS-supported** | Spinlock · **Semaphore** ([[Edsger Dijkstra]] 1965, P·V) · Eventcount/Sequencer |
| **Language** | **Monitor** (critical data + CS + 조건변수 wait/signal + Entry/Condition/Signaler queue) |

### 고전 문제 4종
- Producer-Consumer
- Reader-Writer
- Dining Philosopher
- 단순 ME·Sync
