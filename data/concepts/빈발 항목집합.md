# 빈발 항목집합

[[연관규칙마이닝]]의 1단계 산출물. 지지도가 최소 임계치(minsup) 이상인 항목집합.

## 지지도

- **지지도 카운트** σ(X): X가 포함된 트랜잭션 수.
- **지지도** s(X) = σ(X) / |트랜잭션|.
- **빈발** ⇔ s ≥ minsup.

## anti-monotone 성질

> 항목집합이 커질수록 지지도는 **줄거나 같음**.
>
> ⇒ 어떤 항목집합이 빈발하면 모든 부분집합도 빈발 ([[Apriori]] 원리의 근거).

## 변종

| 종류 | 정의 | 용도 |
|---|---|---|
| 빈발 (frequent) | s ≥ minsup | 기본 |
| **최대** (maximal) | 직접 모집합 모두 비빈발 | 긴 패턴 생성 |
| **닫힌** (closed) | 직접 모집합 모두 지지도가 다름 | 지지도 정보 보존 |

포함 관계: Maximal ⊆ Closed ⊆ Frequent.

## 격자 순회 전략

- General-to-specific vs Specific-to-general vs Bidirectional.
- Prefix tree vs Suffix tree.
- Breadth-first vs Depth-first.

## 생성 알고리즘

- **[[Apriori]]** — 후보 생성 + 가지치기.
- **[[FP-Growth]]** — 후보 없는 트리 기반.
- **Eclat** — 수직 TID 리스트.
