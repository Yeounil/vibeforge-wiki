# 관계형 데이터 모델

1970년 [[E.F. Codd]]가 논문 *"A Relational Model for Large Shared Data Banks"* (Communications of the ACM)에서 제안한 데이터 모델. 데이터를 **테이블(관계)** 의 집합으로 표현.

## 역사적 위치

| 연도 | 사건 |
|---|---|
| 1960s 초 | 네트워크 모델 ([[Charles Bachman]], GE) |
| 1960s 말 | 계층 모델 (IBM IMS) |
| **1970** | **Codd 논문** — 관계형 모델 제안 |
| 1974 | IBM **System R** (최초 관계형 DBMS 프로토타입, **SQL** 도입) |
| 1978 | **[[Oracle]]** (최초 상업용 관계형 DBMS) |
| 1980s~ | 관계형 모델이 산업 표준으로 자리 |

현재 대부분의 상용 DBMS는 관계형 모델 기반 (또는 ORDBMS로 확장).

## 이 강의에서의 위치

DB 강의 (2026 봄학기)의 **근간 모델**. 이후 주차에서 점진적으로 심화:

- **2주차** — 관계 구조·스키마, [[관계 대수]]
- **3주차** — [[관계 연산자]], [[조인 연산자]]
- **4주차** — [[무결성 제약조건]], [[데이터 모델링]]
- **5주차** — [[ER 모델]] → 관계형 매핑
- **6주차** — [[정규화]]
- **7주차** — [[SQL]] 실습

## 주요 구성 요소 (2주차 상세)

- **[[릴레이션]]** — 2차원 테이블 = 튜플 집합
- **튜플/속성/도메인** — 행/열/값 범위
- **차수** · **카디널리티**
- 4대 특성: 튜플 유일성·무순서성 · 속성 무순서성·원자성

## 수학적 기반

- **[[집합론]]** ([[Georg Cantor]]) — 릴레이션 = 튜플의 집합, 관계 대수 연산 = 집합 연산.

## 질의 언어

- **[[관계 해석]]** — 선언적 (→ [[SQL]])
- **[[관계 대수]]** — 절차적 (→ 질의 최적화)
