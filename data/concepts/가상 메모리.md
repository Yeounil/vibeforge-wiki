# 가상 메모리

**프로그램을 여러 block으로 분할하여 필요한 block만 메모리에 적재하고 나머지는 swap device에 두는 non-continuous allocation 방식**. 프로세스 관점에서는 연속 메모리로 보이지만 실제는 분산 적재 (address mapping으로 은폐).

## 핵심 포인트

### 기법 3종
| 기법 | 분할 단위 | 특징 |
|---|---|---|
| **Paging** | 고정 크기 page / page frame | PMT · **No external frag** · Windows 4KB |
| **Segmentation** | 논리적 segment (가변) | SMT · RWE protection · No internal frag · sharing 쉬움 |
| **Hybrid** | Segment → pages | SMT + PMT per segment · 메모리 접근 3배 |

### Address Mapping 3종 (Paging)
- **Direct**: PMT 커널 저장. 메모리 2배 접근.
- **Associative (TLB)**: 병렬 탐색. 고가 HW.
- **Hybrid Direct/Associative**: TLB(최근 PMT entry) + 커널 PMT. **Locality 활용**.

### VM 관리 (Lec10)
**목적**: Page fault rate 최소화.

**6대 SW 전략**: Allocation · Fetch · Placement · Replacement · Cleaning · Load control.

**교체 알고리즘 11종**:
- Fixed allocation: MIN([[László Bélády|Bélády]] 1966) · Random · FIFO(+Belady's anomaly) · LRU · LFU · NUR · Clock · Second chance.
- Variable allocation: **WS (Working Set, [[Peter Denning|Denning]] 1968)** · PFF · VMIN.

**Thrashing**: Over-loaded 시 과도한 page fault → throughput 붕괴.
