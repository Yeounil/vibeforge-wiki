# FP-Growth

[[연관규칙마이닝|연관규칙]] 마이닝의 **후보 생성 없이** 빈발 패턴을 찾는 알고리즘. Frequent-Pattern Tree(FP-Tree)에 DB를 압축 후 분할정복.

## [[Apriori]] 대비 우위

| Apriori 병목 | FP-Growth 해법 |
|---|---|
| 많은 후보 (10⁴ → 10⁷) | **후보 생성 없음** |
| 반복 DB 스캔 (n+1회) | **스캔 2회** |

## FP-Tree 생성 절차

1. DB 1차 스캔 → 빈발 1-항목집합과 빈도 계산.
2. 각 트랜잭션 항목을 **빈도 내림차순** 정렬 → 자주 등장하는 항목이 트리 상위에 공유됨.
3. DB 2차 스캔 → 트리에 경로로 삽입 (prefix 공유).

### 특징

- **완전성**: 긴 패턴 보존 (정보 손실 없음).
- **간결성**: 불필요한 항목 제거, 빈도 정렬로 공유율↑.
- **헤더 테이블 + 노드 링크**: 동일 항목 노드들을 연결 리스트로.

## 마이닝 — 분할정복

마지막 항목부터 시작:

1. 해당 항목의 **조건부 패턴 기반** 구성 (노드 링크 따라가며 prefix 경로 수집).
2. 조건부 FP-Tree 생성.
3. 재귀적으로 마이닝.
4. 트리가 비거나 단일 경로가 될 때까지.

### 예제 (minsup=3)

- `m`의 조건부 패턴 기반: `{(fca:2), (fcab:1)}`
- `m`의 조건부 FP-Tree: `{(f:3, c:3, a:3)} | m` (단일 경로)
- → m 포함 모든 빈발 패턴: m, fm, cm, am, fcm, fam, cam, fcam.

## FP-Tree 속성

- **노드-링크 속성**: 헤더 테이블의 포인터를 따라가면 해당 항목을 포함한 모든 빈발 항목집합 도달 가능.
- **접두사 경로 속성**: 노드의 빈도는 접두사 서브경로의 누적과 같음.
