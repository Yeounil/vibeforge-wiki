# 스케줄링

**제한된 자원(CPU 등)을 어느 프로세스/작업에 언제·얼마만큼 할당할지 결정하는 정책**. 시스템 성능(throughput·response time·utilization·fairness·predictability)의 핵심.

## 핵심 포인트

### 3단계 스케줄링
- **Long-term (Job admission)**: 다중 프로그래밍 degree 조절.
- **Mid-term**: 메모리 swap in/out (저부하·고부하 조절).
- **Short-term (Dispatcher)**: 매 ms 단위, 가장 빈번. CPU 할당 결정.

### 정책 축
- **Preemptive vs Non-preemptive**
- **Priority — Static vs Dynamic (aging)**

### 7대 CPU 알고리즘
| 알고리즘 | 특징 |
|---|---|
| **FCFS** | 도착 순, Convoy effect |
| **RR** | Time quantum, 공평 |
| **SPN (=SJF)** | WT 최소, starvation |
| **SRTN** | SPN 선점형 |
| **HRRN** | Ratio=(WT+BT)/BT, aging |
| **MLQ** | 큐 고정 |
| **MFQ** | 큐 이동·dynamic |

### Disk scheduling 재사용
- Lec12에서 FCFS/SSTF/Scan/C-Scan/Look이 **disk scheduling에서 재등장**. 스케줄링 원리는 자원 종류 무관.
