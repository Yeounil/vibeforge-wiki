# ER 모델 (Entity-Relationship Model)

1976년 **[[Peter Chen]]** 이 제안한 **개념적 데이터 모델**. 현실 세계를 **개체(Entity)**, **속성(Attribute)**, **관계(Relationship)** 로 모델링. [[데이터 모델링]] 3단계 중 **개념 모델링**의 표준 도구.

산출물은 **[[ER 다이어그램]](ERD)**.

## 3대 구성요소

- **개체(Entity)** — 업무상 지속 관심 대상
- **속성(Attribute)** — 개체의 특성. **식별자(Identifier)** 는 특수 속성
- **관계(Relationship)** — 개체 간 연관

## 개체 (Entity)

**개체가 되기 위한 6조건**: 업무 필요 · 유일 식별 · 영속성 · 프로세스 이용 · 속성 포함 · 관계 1개 이상.

구조: 개체 타입 → 개체 → 속성 → 속성값.

## 속성 분류

- **기본 속성** — 업무 분석으로 직접 정의
- **설계 속성** — 모델링 중 새로 정의·변형
- **파생 속성** — 다른 속성 영향으로 계산. 적게 정의 권장.

## 식별자 (Identifier)

- **본질 식별자** — 집합 본질을 설명
- **후보 식별자** — 유일 식별 가능
- **대체(보조) 식별자** — 원래 식별자 대신 사용 가능
- **인조 식별자** — 임의 값으로 신설 (예: 사원번호)
- **실질 식별자** — 공식적 부여

논리 단계에서 "식별자", 물리 단계에서 "키" — [[키]] 참조.

## 관계 (Relationship)

**목적별**: 존재에 의한 관계 / 행위에 의한 관계.

**매핑 카디널리티** (함수성 기반):

| 차수 | 예 | 특징 |
|---|---|---|
| **1:1** | 신랑-신부 | 드묾. 수직 분할 결과 |
| **1:M** | 부모-자식 | **가장 흔함** |
| **M:1** | 교수-학과 | |
| **M:M** | 등록-과목 | 모델링 완료 후 사라짐. **관계 개체**로 해소 |

**참여 유형**: 전체 참여(Total) vs 부분 참여(Partial). 4조합: 필수-필수·필수-선택·선택-필수·선택-선택.

## 약한 개체 타입

자기 속성만으로 키 명세 불가능. 강한 개체에 존재 종속.
- **구별자(부분키)** — 약한 개체들을 서로 구별
- **식별 관계 타입** — 약한 개체를 강한 개체에 연결

예: 대부(주 개체) - 상환(약한 개체).

## 확장된 ER (EER)

서브타입 지원 추가 → Extended ER Model.
