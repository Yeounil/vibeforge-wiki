# 순차패턴

[[데이터마이닝]]의 **서술 방법**. 각 객체가 이벤트의 **시간 순서**를 가질 때, 이벤트 간 순차 의존 규칙을 찾는 작업.

규칙은 시간 제약(timing constraints) 내에서 성립해야 함.

## 예제

### 통신 알람 로그

```
(Inverter_Problem  Excessive_Line_Current) (Rectifier_Alarm) → (Fire_Alarm)
```

### POS 트랜잭션 시퀀스

| 스토어 | 순차 패턴 |
|---|---|
| 컴퓨터 서점 | (Intro_To_Visual_C) (C++_Primer) → (Perl_for_dummies, Tcl_Tk) |
| 스포츠용품점 | (Shoes) (Racket, Racketball) → (Sports_Jacket) |

## [[연관규칙마이닝]]과의 차이

| | 연관규칙 | 순차패턴 |
|---|---|---|
| 시간 | **무관** | 순서가 중요 |
| 규칙 형태 | X → Y (동시) | 이벤트 시퀀스 → 이벤트 |
