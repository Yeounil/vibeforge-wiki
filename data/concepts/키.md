# 키 (Key)

[[릴레이션]] 내에서 **튜플을 유일하게 식별할 수 있는 속성들의 집합**.

## 기본 성질

- **유일성(Uniqueness)** — 서로 다른 두 튜플의 키 값이 같지 않음.
- **최소성(Minimality)** — 식별에 필요한 최소 속성들로만 구성.

## 5가지 키

| 키 | 유일성 | 최소성 | 역할 |
|---|---|---|---|
| **수퍼키** (Superkey) | O | × | 유일 식별 가능한 모든 속성 집합 |
| **후보키** (Candidate Key) | O | O | 수퍼키의 최소 부분집합 |
| **기본키** (Primary Key, PK) | O | O | DBA가 지정한 하나의 후보키. **NULL 불가** |
| **대체키** (Alternate Key) | O | O | 후보키 중 PK 제외 |
| **외래키** (Foreign Key, FK) | — | — | 다른 릴레이션의 PK 참조 |

## 기본키의 중요성

[[관계형 데이터 모델]]의 **값에 의한 참조**(주소 아닌 값) 기반. 릴레이션 이름과 PK만 있으면 해당 튜플을 항상 찾을 수 있음.

- 유일성 — 키 값을 가지는 속성 집합은 항상 하나만.
- 불변성 — 시간이 지나도 키의 성질은 불변.

## 외래키

`R1`의 속성 FK가 `R2`의 **기본키**와 같은 도메인일 때:
- R1 = **참조 릴레이션**
- R2 = **피참조 릴레이션**
- R1 = R2도 가능 (자기 참조; 예: 사원-관리자 관계)

## 관련 제약

- [[무결성 제약조건]] — 개체 무결성(PK NOT NULL), 참조 무결성(FK는 PK 또는 NULL)
