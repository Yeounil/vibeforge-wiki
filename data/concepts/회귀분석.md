# 회귀분석

[[데이터마이닝]]의 **예측 방법**. 연속값 변수의 미래 값을 다른 변수 값들로부터 예측.

## 모델

- **선형** (linear) — 직선 관계 가정.
- **비선형** (nonlinear) — 다항·지수·로그 등.

## 출발 분야

통계학 · 신경망 (neural network).

## 대표 알고리즘

- Linear regression
- k-Nearest Neighbor regression
- Regression Trees
- Neural Networks

## 예제

- 광고 지출 → 신제품 판매량 예측.
- 온도·습도·기압 → 풍속 예측.
- 주가지수의 시계열 예측.

## 관련

- [[분류]] — 예측 방법이지만 **이산 클래스** 출력.
- [[이상치 탐색]] — 같은 예측 카테고리의 세 번째 기법.
