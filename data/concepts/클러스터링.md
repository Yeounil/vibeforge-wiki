# 클러스터링

[[데이터마이닝]]의 **서술 방법**. 데이터 포인트를 다음 조건으로 그룹핑:

- 클러스터 **내**: 더 유사 (more similar).
- 클러스터 **간**: 덜 유사 (less similar).

## 핵심 요소

- **데이터 포인트** — 여러 속성으로 구성.
- **[[유사도|유사 척도]]** (similarity measure) — 가깝고 먼 정도. 연속 속성은 [[유사도|유클리디안 거리]].

## 대표 알고리즘

- Hierarchical clustering
- k-means clustering

## 응용

| 응용 | 설명 |
|---|---|
| 시장 세분화 | 고객을 부분집합으로. 각 그룹 = 마케팅 타겟. |
| 문서 클러스터링 | 용어 빈도 기반 유사 문서 그룹핑 (예: LA Times 3204 기사). |
| 주식 동향 | 가격 변동을 이벤트화 → 유사 주식 그룹핑. |

## 평가

- 군집 내 분산 작음 + 군집 간 분산 큼 = 좋은 결과.
