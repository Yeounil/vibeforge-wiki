# 아이리스 데이터

[[데이터마이닝]]·기계학습의 대표 예제 데이터셋. 영국 통계학자 Ronald Fisher가 1936년 사용한 이래 표준 벤치마크.

## 구성

- **150개** 아이리스 꽃 레코드.
- 3 종 × 50개:
  - setosa
  - virginica
  - versicolour

## 속성

- sepal length, sepal width — 꽃받침
- petal length, petal width — 꽃잎
- 클래스 (종)

## 용도

- [[분류]] 알고리즘 데모.
- [[클러스터링]] (비지도 — 꽃잎 크기만으로 종 분리 가능 여부).
- 데이터 탐색·시각화 (히스토그램·산포도) 튜토리얼.
