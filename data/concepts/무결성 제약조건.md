# 무결성 제약조건 (Integrity Constraints)

[[데이터 모델]]의 **제약조건(C)** 요소. 데이터베이스 상태가 항상 만족해야 하는 기본 규칙. 사용자가 명시하면 [[DBMS]]가 상태 변이마다 자동 검사·유지.

## 3가지 유형

| 제약 | 정의 | 핵심 |
|---|---|---|
| **개체 무결성** (Entity Integrity) | 기본키 값은 **NULL 불가** | 식별 불가능한 튜플 방지 |
| **참조 무결성** (Referential Integrity) | 외래키는 피참조 PK 값 혹은 NULL | 존재하지 않는 튜플 참조 방지 |
| **도메인 무결성** (Domain Integrity) | 속성 값은 해당 도메인 내 | 잘못된 값 방지 |

## NULL의 의미

- **정보의 부재**, 혹은 **아직 정해지지 않음**
- 기본키가 NULL → 튜플 식별 불가 → 개체 정의 모순 → **개체 무결성 위반**
- 외래키는 NULL 허용 가능 (추가 제약으로 금지 가능)

## 갱신 연산 시 위반 처리

### 삽입

- 도메인 위반 / PK 중복 / 참조 대상 없음 → **거부 혹은 경고**

### 삭제

피참조 튜플 삭제 시 참조 무결성 위반 가능. 3가지 옵션(사용자 선택):

1. **삭제 거부**
2. **연쇄 삭제(Cascade)** — 참조 튜플도 모두 삭제
3. **NULL 치환 또는 다른 유효 튜플 참조**

### 수정

"삭제 + 삽입"으로 간주 → 두 연산의 모든 문제 재현. 단, **비-키 속성** 변경은 문제없음.
