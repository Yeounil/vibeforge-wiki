# 메모리 관리

**OS가 물리 메모리를 프로세스들에게 할당·회수·보호하는 기법**. Continuous allocation(연속 할당) 영역. [[가상 메모리]](non-continuous)의 선행 개념.

## 핵심 포인트

### Address Binding — 주소 결정 시점 3종
| 시점 | 방식 |
|---|---|
| **Compile-time** | 메모리 위치 고정 (단순 시스템) |
| **Load-time** | 적재 시 결정 |
| **Run-time (MMU)** | 실행 시 동적 변환. **대부분 OS 사용**. Relocation register |

### Continuous Allocation 분류
- **Uniprogramming**: 프로세스 1개. Degree=1. Overlay·Boundary register.
- **Multiprogramming**:
  - **FPM (Fixed Partition)**: 고정 크기 분할. Degree=K. **Internal + External fragmentation**.
  - **VPM (Variable Partition)**: 동적 분할. **No internal / External fragmentation**.

### VPM 배치 4전략
- **First-fit**: 처음 맞는 자리.
- **Best-fit**: 가장 작게 남는 자리.
- **Worst-fit**: 가장 크게 남는 자리.
- **Next-fit**: 마지막 위치부터 순환.

### Fragmentation 대응
- **Coalescing holes**: 인접 빈 공간 병합 (저 overhead).
- **Storage compaction**: 전체 통합. 프로세스 중지 필요 (고 overhead).

### 처리 흐름
Source → Compiler → Linker → Loader → Image. **Dynamic loading**은 호출 시점 적재로 효율화.
