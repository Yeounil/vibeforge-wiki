# 관계 연산자

[[관계 대수]]에서 [[릴레이션]]을 다루는 연산자 집합.

## 일반 집합 연산자 (호환성 필요)

| 연산자 | 기호 | 결과 |
|---|---|---|
| 합집합 | `∪` | R 또는 S |
| 교집합 | `∩` | R ∩ S |
| 차집합 | `−` | R에는 있고 S엔 없음 |
| 카티션 곱 | `×` | 모든 튜플 쌍 (호환성 불필요) |

**합병 호환성**: 차수·타입·의미 일치. 의미(semantic) 확인은 사람 책임.

## 순수 관계 연산자

| 연산자 | 기호 | 설명 |
|---|---|---|
| **셀렉션** (Selection) | `σ_조건(R)` | 조건 만족 튜플 — 행 필터 |
| **프로젝션** (Projection) | `π_속성(R)` | 특정 속성 — 열 추출, 중복 제거 |
| **[[조인 연산자]]** (Join) | `R ⋈_조건 S` | 두 릴레이션 결합 |
| **디비전** (Division) | `R ÷ S` | "모든 ~에 대한" — SQL 직접 미지원 |
| **개명** (Rename) | `ρ_S(E)` | 중간 결과·속성 이름 부여 |

## 집단 연산자 (Aggregation, 확장)

기본 관계 연산 외에 추가. `ℱ_<함수>(R)`.

함수: **SUM, MAX, MIN, AVG, COUNT**.

그룹별 집계: `<그룹화속성> ℱ <함수>(R)`

## 근원 연산 5개

`σ, π, ∪, −, ×` — 이 5개로 대부분의 관계 대수 표현 가능.

복합 연산들은 근원 연산의 합성:
- `R ⋈_c S = σ_c(R × S)`
- `R ∩ S = R − (R − S)`

## 최적화 직관

- **선택율**(σ가 남기는 비율) 낮은 연산을 먼저.
- π는 최대한 나중에, 혹은 테이블 크기를 줄이기 위해 밀어넣음.
- 교환·결합 법칙 활용 (합집합·교집합은 성립, 차집합은 불성립).
