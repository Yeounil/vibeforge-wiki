# 분류

[[데이터마이닝]]의 **예측 방법** 중 하나. 미리 정의된 클래스 중 하나를 레코드에 부여.

## 입력

- 레코드 — 여러 속성 + **클래스** 부여.
- **훈련 집합** (training set): 모델 구성용.
- **테스트 집합** (test set): 정확성 검증용.

## 3단계

1. **모델 구성** — 속성 → 클래스 함수 학습.
2. **모델 검증** — 테스트셋으로 정확성 판별.
3. **예측 적용** — 미분류 레코드에 클래스 부여.

## 대표 알고리즘

- Logistic regression
- k-Nearest Neighbor
- Naïve Bayes
- Classification Trees
- Neural Networks
- Linear Discriminant Analysis

## 응용

- **우편 마케팅** — buy / don't buy.
- **신용카드 사기 적발** — 평소 결제 패턴과 다른 트랜잭션.
- **이탈 고객 예측** — 충성 vs 비충성.

## 관련

- [[회귀분석]] — 같은 예측 방법이지만 **연속값** 출력.
- [[이상치 탐색]] — 예측 방법이지만 클래스 아닌 **이상 여부** 판별.
