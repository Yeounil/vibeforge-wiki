# 정규화 (Normalization)

[[릴레이션]] 설계 시 속성들 간의 연관성을 분해하여 별개의 릴레이션으로 표현, **이상 상태(Anomaly)** 를 제거하는 과정. [[데이터 모델링]]의 **논리** 단계 핵심 작업.

## 이상 상태 (Anomaly)

한 릴레이션에 여러 개체 정보가 혼재될 때 발생:

| 이상 | 증상 |
|---|---|
| **삽입 이상** | 원치 않는 정보 강제 삽입 필요 |
| **삭제 이상** | 삭제 시 연쇄적 정보 손실 |
| **갱신 이상** | 중복 튜플 일부만 갱신 → 비일관성 |

원인: **한 튜플이 여러 개체 표현** → 속성 간 연관성 중복.

## 3원칙

1. **정보 표현의 무손실** — 분해 후에도 원본 정보 복구 가능.
2. **최소 데이터 중복**.
3. **분리의 원칙** — 독립 관계성은 별도 릴레이션.

## 정규형 단계

| 정규형 | 조건 | 제거 대상 |
|---|---|---|
| **1NF** | 모든 속성 도메인이 **원자값** | 반복 그룹 |
| **2NF** | 1NF + 키가 아닌 속성은 **PK에 완전 함수 종속** | 부분 함수 종속 |
| **3NF** | 2NF + 키가 아닌 속성은 PK에 **이행적 종속 없음** | 이행적 FD |
| **BCNF** | 모든 **결정자가 후보키** | 후보키 중첩 문제 |
| **4NF** | BCNF + 다치 종속 제거 | 다치 종속 |
| **5NF** | 4NF + 조인 종속 제거 | 조인 종속 |

1NF → 2NF → 3NF → BCNF → 4NF → 5NF 순으로 **더 엄격**.

설계 목표 = 모든 릴레이션 **BCNF 또는 3NF**.

## 무손실 분해

`R = R1 ∪ R2`로 분해 후 자연 조인 `R1 ⋈ R2`로 R 복구 가능해야 함.

조건: `R1 ∩ R2 → R2 − R1` (또는 역) 성립.

`R(A, B, C)`에서 `B → C` 존재 → `R1(A, B)` + `R2(B, C)` 무손실.

## 이진 릴레이션의 특수성

속성 2개만 있는 릴레이션은 **자동으로 BCNF** — 이행적 FD가 존재하려면 3개 속성이 필요하므로.
