# 파일 시스템

**사용자 파일을 관리하는 OS의 한 부분**. File + Directory + Partition 3요소로 구성되며, 보조 기억 장치(disk) 위에 논리적 추상화 계층을 제공.

## 핵심 포인트

### 3요소
- **File**: 연관 정보의 집합. 보조 기억 장치 할당의 최소 단위. Attribute 7종 (Name·ID·Type·Location·Size·Protection·Time).
- **Directory**: 파일 분류·보관 구조.
- **Partition** (minidisks·volumes·virtual disk): 디렉터리 집합을 논리/물리 구분.

### Directory 구조 5종 (진화 순)
Flat → 2-level (MFD+UFD) → **Hierarchical (tree, 대부분 OS)** → Acyclic graph (Unix symbolic link) → General graph (cycle + infinite loop).

### File Access Method 3종
- **Sequential** (`fgetc()`)
- **Direct** (`lseek()`, `seek()`)
- **Indexed**

### File Protection
- **접근 연산 RWXA**.
- **Access matrix** (Domain × Object) 구현 4종:
  - Global table · **Access list** (UNIX rwx owner/group/universe) · Capability list (kernel 저장) · Lock-key.
  - 실제 OS: access list + capability 혼용.

### Allocation Methods 3종
| 기법 | 특징 |
|---|---|
| **Continuous** | 순차/직접 접근 효율, external frag |
| **Linked** | No external frag, 직접 접근 비효율, **FAT** (MS-DOS·Windows) |
| **Indexed** | Index block per file, 직접 접근 효율, **Unix** |

### Free Space 관리 4종
Bit vector · Linked list · Grouping · Counting.

### Mounting
현재 file system에 다른 file system 붙이기 (mount point).
