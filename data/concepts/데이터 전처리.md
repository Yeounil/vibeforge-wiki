# 데이터 전처리

[[데이터마이닝]]의 필수 선행 단계. 원본 데이터는 거의 항상 불완전 → 분석 가능한 형태로 다듬는 작업.

## 필요한 이유 (품질 문제)

- **측정 오류** — 사람·장비 한계.
- **노이즈** — 원본 값을 변경하는 임의 잡음.
- **[[이상치 탐색|이상치]]** — 다른 객체와 크게 다른 객체.
- **누락 값** — 수집 실패·적용 불가.
- **중복 데이터** — 특히 여러 소스 통합 시.
- **불일치** — 동일 개체에 다른 값.

## 5단계

1. **데이터 수집** — 응용에 맞춰 정의.
2. **데이터 정제** — 누락값·잡음·이상치 교정. Imputation.
3. **데이터 통합** — 여러 DB/파일 병합.
4. **데이터 축소** — 집계·샘플링·특징 선택·[[차원의 저주|차원 축소]].
5. **데이터 변환** — 정규화·이산화·집계.

## 특징 추출 & 변환

| 데이터 | 기법 |
|---|---|
| 센서 | 웨이블릿·푸리에 변환 |
| 이미지 | 픽셀·컬러 히스토그램·시각적 단어·CNN |
| 문서 | Bag-of-words, 불용어 제거 |
| 웹 로그 | 필드 파싱 → 다차원 표현 |

### 형식 변환

- **Numeric → Categorical**: 이산화 (Equi-width / Equi-depth / Equi-log).
- **Categorical → Numeric**: 이진화 (X개 값 → X개 이진 속성).

## 데이터 축소 4가지

| 기법 | 축소 축 |
|---|---|
| 집계 (aggregation) | 속성·객체 병합 (도시→국가, 일→월) |
| 샘플링 (sampling) | 행 |
| 특징 선택 (feature selection) | 열 |
| 차원 축소 ([[PCA]]) | 열 (새 기저) |

## 정규화

- Z-score: (value − mean) / std.
- 변수별 측정 단위 차이 제거 (나이 vs 연봉).
