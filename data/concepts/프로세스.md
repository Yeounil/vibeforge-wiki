# 프로세스

**실행 중인 프로그램**. 시스템 자원(메모리·파일·장치)과 제어 정보를 포함하는 OS의 기본 작업 단위. Job(정적 프로그램)과 구분된다.

## 핵심 포인트

- **PCB (Process Control Block)**: 프로세스의 모든 상태를 담는 커널 자료구조. PID·상태·PC·레지스터·메모리 정보·open file 등.
- **프로세스 상태 전이**: Created → Ready ↔ Running → Blocked → Terminated. Suspended(swap out) 상태 추가 시 7-state.
- **Context switching**: 현 프로세스 PCB 저장 → 다음 프로세스 PCB 복원. 순수 overhead.
- **Interrupt 7종**이 상태 전이를 유발 (I/O complete·Timer·SVC·Program check·Machine check·Restart·I/O interrupt).
- [[스레드]]는 프로세스 내부의 경량 실행 단위 (자원 공유, 제어 분리).
