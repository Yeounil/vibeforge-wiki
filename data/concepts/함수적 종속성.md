# 함수적 종속성 (Functional Dependency)

어떤 [[릴레이션]] R에서 **속성 X의 값에 대하여 속성 Y의 값이 오직 하나** 연관될 때 Y는 X에 함수 종속. 표기 `X → Y`.

- **X** = 결정자 (Determinant)
- **Y** = 종속자 (Dependent)

## 기본 성질

- X가 키이면 R의 모든 속성 Y에 대해 `X → Y`.
- X가 꼭 키일 필요는 없음. 예: "1자녀 정책"에서 `보호자 → 학생명`.
- X의 한 값에 대응되는 Y 튜플이 여러 개여도 속성값은 하나.

## 종류

### 완전 함수 종속 (Full FD)

X의 어떤 **진부분집합 X'** 에 대해 `X' → Y` 성립 안 함. X 전체가 필요.

### 부분 함수 종속 (Partial FD)

X의 일부 부분집합만으로 Y 결정 가능. **2NF 위반**의 원인.

예:
```
수강(학번, 과목번호, 지도교수, 성적)  PK={학번, 과목번호}
{학번, 과목번호} → 성적  (완전)
학번 → 지도교수          (부분 — 위반)
```

### 이행적 함수 종속 (Transitive FD)

`A → B` 이고 `B → C` 이면 `A → C`는 이행적. **3NF 위반**의 원인.

예:
```
사원정보(사번, 이름, 부서번호, 부서명)
사번 → 부서번호
부서번호 → 부서명
→ 사번 → 부서명 (이행적)
```

## [[정규화]]와의 관계

| 정규형 | 제거하는 FD |
|---|---|
| 2NF | 부분 함수 종속 |
| 3NF | 이행적 함수 종속 |
| BCNF | 후보키 아닌 결정자에 의한 종속 |
