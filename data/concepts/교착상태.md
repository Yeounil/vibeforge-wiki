# 교착상태

**둘 이상의 프로세스가 서로 상대방의 자원 해제를 기다리며 무한 대기하는 상태**. Blocked·Starvation과 구분되는 고유한 실패 모드.

## 핵심 포인트

### 4대 필요 조건 (모두 성립해야 발생)
1. **Exclusive use** (상호 배제): 자원을 한 프로세스만 사용.
2. **Non-preemptible** (비선점): 강제 회수 불가.
3. **Hold & Wait**: 자원 보유하면서 추가 자원 요청.
4. **Circular wait**: 순환 의존.

### 자원 분류 5축
HW/SW · Preemptible · 할당 단위 · Exclusive · SR(Serially reusable) vs CR(Consumable).
→ Deadlock 유발 조건: **Non-preemptible + Exclusive + SR**.

### 3대 해결 접근
| 접근 | 기법 |
|---|---|
| **Prevention** | 4 조건 중 하나 제거 (비현실적) |
| **Avoidance** | Safe state 유지. **Banker's algorithm** ([[Edsger Dijkstra]], 1 type) · Habermann (다 type) |
| **Detection + Recovery** | RAG graph reduction · cycle/knot detection. Recovery: process termination·resource preemption·checkpoint-restart |

### Blocked vs Deadlock vs Starvation
- **Blocked**: 일시적 대기 (I/O 등).
- **Deadlock**: 시스템 개입 없이는 영구 대기.
- **Starvation**: 알고리즘 편향으로 무한 연기.
