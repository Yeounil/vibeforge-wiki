# 디스크 관리

**I/O HW와 디스크 레벨에서의 성능·신뢰성 관리 기법**. I/O mechanism, OS I/O 서비스, disk scheduling, RAID 아키텍처를 포함.

## 핵심 포인트

### Disk 구조 (Lec11 선행)
- **Disk pack**: Sector → Track → Cylinder → Platter → Surface.
- **Disk drive**: Head · Arm · Positioner · Spindle (RPM).
- **Data access time** = Seek time + Rotational delay + Data transmission time.

### I/O Mechanisms 3종
| 기법 | 방식 |
|---|---|
| **Polling** | Processor가 주기적 확인. Simple·부담 큼 |
| **Interrupt** | I/O 장치가 완료 신호. Low overhead |
| **DMA** | Processor 개입 없이 I/O ↔ memory. Processor는 시작/종료만 |

### OS I/O 서비스
- **I/O scheduling** · Error handling · Device info 관리.
- 성능 개선: **Buffering** (속도 차이) · **Caching** (hit 시 I/O 생략) · **Spooling** (공유 I/O 장치).

### Disk Scheduling (평가 3축: Throughput · Response time · **Predictability**)

#### Seek time 최적화 5종
| 알고리즘 | 특징 |
|---|---|
| **FCFS** | 도착 순. 공평·무고려 |
| **SSTF** | 가장 가까운 요청. Throughput↑·starvation |
| **Scan** | 엘리베이터. 양방향 끝까지 |
| **C-Scan** | 한 방향만. 균등 |
| **Look** | Scan 실제 구현. 끝까지 안 감 |

#### Rotational delay 최적화
- **SLTF (Sector queueing)**: Fixed head disk·drum disk용. Sector별 queue.

#### 통합
- **SPTF** (Shortest Positioning Time First) = Seek + Rotational 최소.

### RAID Architecture 5종
| Level | 방식 | 특징 |
|---|---|---|
| **RAID 0** | Striping | 성능↑·신뢰성↓ |
| **RAID 1** | Mirroring (2-disk) | 신뢰성↑·용량/2 |
| **RAID 3** | Byte + parity disk | Parity 병목 가능 |
| **RAID 4** | Block + parity disk | Parity 병목 |
| **RAID 5** | Block + **parity 분산** | **현재 최다 사용** |
