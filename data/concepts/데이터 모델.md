# 데이터 모델

컴퓨터가 인식·처리할 수 있는 **데이터의 논리적 구조**. DBMS와 사용자의 공통 인식 기반.

## 3요소 (S·O·C)

| 요소 | 성격 | 예 (정수형) |
|---|---|---|
| **구조 (Structure, S)** | 정적 — 개체와 관계 | `..., -1, 0, 1, ...` |
| **연산 (Operation, O)** | 동적 — 조작 방식 | `+`, `−`, `×`, `÷` |
| **제약조건 (Constraint, C)** | 논리적 한계 | 정수/정수가 정수 아닐 수 있음 |

## 3가지 표현 관점 (사용자 → DBMS → 저장장치)

1. **개념적 구조** — 사용자 입장. **개체(Entity)** + **관계(Relationship)**. → [[ER 모델]] (5주차)
2. **논리적 구조** — 컴퓨터 관점. DBMS와 사용자의 공통 인식. → [[관계형 데이터 모델]]
3. **물리적 구조** — 저장 미디어 관점. 디스크·SSD 위의 실제 배치.

논리-물리 매핑은 DBMS가 처리 → [[데이터 독립성]] 확보.

## 모델의 역사적 변천

계층 모델 → 네트워크 모델 ([[Charles Bachman]]) → **[[관계형 데이터 모델]]** ([[E.F. Codd]] 1970, 현재 주류) → 객체 지향 모델 → **객체 관계형 모델**.
