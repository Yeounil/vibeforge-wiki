# ER 다이어그램 (ERD)

[[ER 모델]]의 도식 표현. 정보 공학 기반 데이터 모델링의 **핵심 산출물**이며, 업무 데이터 흐름과 프로세스 연관을 논의하는 의사소통 도구.

## 주요 표기법 6종

| 표기법 | 특징 | 실무 |
|---|---|---|
| **Chen (원조)** | 개체=사각형, 관계=마름모, 속성=타원 | 대학 교재 / 실무 ×  |
| **IDEF1X** | 마름모+원 사용 | ERWin |
| **IE / Crow's Foot** | 1981 Finkelstein·Martin. **다 쪽에 까마귀 발** | **실무 주류** |
| **바커 (Barker)** | 영국 CACI → Richard Barker. 오라클 Case Method | 실무 (오라클 계열) |
| **Min-MAX / ISO** | 기수성 정교 표기 | 드묾 |
| **UML** | `<<Entity>>` 스테레오타입 | 객체지향 통합 (Rational Rose) |

IE ↔ 바커는 **상호 전환 가능** — 하나만 알면 다른 쪽도 이해 용이.

## 바커 표기법 핵심

### 개체 & 속성

- **개체**: 네 모서리가 둥근 **소프트박스** + 개체명
- **속성 상태**:
  - `*` (Mandatory) — 필수
  - `o` (Optional) — 선택
- **식별자**: `#` 기호. 복합 식별자는 `#` 반복.

### 관계 구문 (7단계 템플릿)

```
[개체1의 임의의 하나는]
  [단 하나의 | 하나 이상의] [개체2를]
  [관계명이]
  [반드시 되어야 한다 | 될 수도 있다]
```

**양방향**으로 각각 기술.

예:
- "각 사원은 하나의 부서에 **반드시** 근무한다."
- "각 부서에 한 명 이상의 사원이 근무할 **수도 있다**."

### 서브타입

슈퍼타입 상자 안에 서브타입을 상자로 중첩. 공간 절약 + 상호 배타성.

## IE / Crow's Foot 핵심

관계의 "다(Many)"를 **까마귀 발** 기호로 표현. 선택성은 ○·✕ 등으로 표기. 실무 DB 설계 대부분에서 기본.
