# 릴레이션 (Relation)

[[관계형 데이터 모델]]의 기본 구성 단위. **2차원 테이블**이며 수학적으로는 **튜플들의 집합**.

## 구성 요소

| 용어 | 의미 | 테이블 |
|---|---|---|
| **튜플(Tuple)** | 행 | Row |
| **속성(Attribute)** | 열 | Column |
| **도메인(Domain)** | 속성이 가질 수 있는 값의 집합 | 타입 |

## 형식 정의

`R ⊆ D₁ × D₂ × ... × Dₙ` — n개 도메인의 **카티션 프로덕트의 부분집합**.

- **릴레이션 스키마** `R(A₁,...,Aₙ)` — 이름과 속성 목록.
- **릴레이션 인스턴스** — 특정 시점의 튜플 집합.

## 크기 지표

- **차수(Degree)** = 속성의 수(열 수).
- **카디널리티(Cardinality)** = 튜플의 수(행 수).

## 4대 특성

1. **튜플의 유일성** — 집합이므로 중복 튜플 불가.
2. **튜플의 무순서성** — 집합이므로 순서 없음.
3. **속성의 무순서성** — 스키마도 집합.
4. **속성의 원자성(Atomicity)** — 속성 값은 **원자 값**; 더 쪼갤 수 없음. 반복 그룹 불허 → **정규화 릴레이션**만 허용.
