# 데이터 프레임

[[R]] 언어의 실전 데이터셋 표현 구조. 행·열 2차원이지만 **각 열은 다른 타입** 가능 — 이것이 행렬과의 핵심 차이.

내부적으로는 각 열이 벡터인 **리스트**. 파일/DB에서 읽은 데이터의 기본 컨테이너.

## 생성

```r
data.frame(
  Name   = c("Jin", "Jill"),
  Salary = c(55000, 50000),
  Union  = c(TRUE, TRUE),
  stringsAsFactors = FALSE
)
```

- `stringsAsFactors`: 기본 TRUE → 문자열을 팩터로. 벡터로 쓸 거면 **FALSE 명시**.

### 파일로부터

```r
read.table("file.txt", header = TRUE)
```

## 접근

| 방법 | 주의 |
|---|---|
| `d$kids` | **명확하고 안전**. 권장. |
| <code>d&#91;&#91;"kids"&#93;&#93;</code> | 리스트 방식 동등 |
| `d[, 1]` | 행렬 방식. **벡터로 축소**됨 |
| `d[, 1, drop=FALSE]` | 축소 방지 |

### 필터링

- `d[d$exam1 >= 3.0, ]` — 행렬 유사.

### NA 제거

- `d[complete.cases(d), ]`.

## 결합 — `merge()`

- 관계형 DB의 **조인**과 유사.
- `merge(d1, d2, by = "id")`.
- 이름 다른 경우: `by.x`, `by.y`.
- **중복** 키면 카테시안 곱 발생 → 신중히.

## 함수 적용

- `lapply(d, f)` → 리스트 반환.
- `as.data.frame(result)` + `order()`로 정렬 관계 유지.

- [[조인 연산자]] — R의 `merge()` 대응.
