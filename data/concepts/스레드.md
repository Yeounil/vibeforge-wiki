# 스레드

**프로세스 내부의 경량 실행 단위 (LWP, Lightweight Process)**. [[프로세스]]에서 **자원 소유(code·data·heap·open files)와 제어(PC·레지스터·stack) 분리**로 얻은 구조. 한 프로세스 내 여러 스레드는 자원을 공유하고 제어만 독립.

## 핵심 포인트

- **장점 4**: (1) 응답성, (2) 자원 공유로 메모리 절약, (3) 생성·context switch 경량, (4) 멀티프로세서 활용.
- **TCB (Thread Control Block)**: 스레드별 제어 정보 (PC·레지스터·stack pointer). PCB 대비 경량.
- **구현 모델 3종**:
  - **User-level (n:1)**: 커널 모름. 블록 시 전체 프로세스 블록.
  - **Kernel-level (1:1)**: OS가 직접 관리. 오버헤드 ↑·유연성 ↑.
  - **Hybrid (n:m)**: user thread를 kernel thread에 다중매핑. 예) Solaris.
- 같은 프로세스 스레드 간 context switch는 TLB·캐시 공유로 프로세스 간 switch보다 훨씬 저렴.
