# 관계 대수 (Relational Algebra)

[[릴레이션]]에 대한 **절차적** 질의 언어. "무엇(What)을 **어떻게(How)**" 처리할지를 명시. 수학적 **집합 이론** 기반.

DBMS 내부에서 [[SQL]] 질의를 처리·최적화하는 기반.

## 단항 연산자 (릴레이션 1개)

- **셀렉션(Selection, σ)** — 조건 만족 **튜플** 선택 (행 필터)
- **프로젝션(Projection, π)** — 특정 **속성**만 선택 (열 추출)
- **개명(Rename, ρ)**

## 이항 연산자 (릴레이션 2개)

- **카티션 프로덕트 (×)**
- **조인(Join, ⋈)** — 관련 튜플 결합
- **합집합 (∪) / 교집합 (∩) / 차집합 (−)**

## 폐쇄 성질 (Closure Property)

모든 연산의 입력·출력이 **릴레이션** → 연산 중첩이 자유로움.

```
σ(π(⋈(R, S)))
```

폐쇄 성질이 없으면 절차를 자유롭게 표현하기 어려움.

## [[관계 해석]]과의 비교

| | 관계 대수 | 관계 해석 |
|---|---|---|
| 스타일 | 절차적 (What+How) | 선언적 (What만) |
| 기반 | 집합 이론 | 술어해석 |
| 용도 | 최적화 기반 | 사용자 언어 기반 (SQL) |

**표현력은 두 언어가 동등**.
